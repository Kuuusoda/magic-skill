# 附录E — 瑞士式比赛建议轮数 Recommended Number of Rounds in Swiss Tournaments

以下瑞士轮轮数适用于重要比赛（例如区域冠军赛预选赛）。非重要比赛可由比赛主办人酌情使用。

| 牌手（队伍）人数 | 瑞士轮数 | 淘汰赛 |
|------|------|------|
| 2 | 单淘汰 | 单淘汰 |
| 4（仅限团队赛/双头巨人） | 无（直接进行单淘汰） | 无（直接进行单淘汰） |
| 3 | 单淘汰 | 单淘汰 |
| 5–8 | 无（直接进行单淘汰） | 无（直接进行单淘汰） |
| 9–16 | 4轮（若限制赛且淘汰赛为轮抽）<br>5轮（所有其他赛制） | 前8（若限制赛且淘汰赛为轮抽）<br>前4（所有其他赛制） |
| 17–32 | 5轮 | 前8 |
| 33–64 | 6轮 | 前8 |
| 65–128 | 7轮 | 前8 |
| 129–226 | 8轮 | 前8 |
| 227–409 | 9轮 | 前8 |
| 410+ | 10轮 | 前8 |

团队赛中，每支队伍在此表中视为一位牌手。

在使用授予轮空的比赛中，使用上表时，每位获得 1 轮轮空的牌手应按 2 人计算，每位获得 2 轮轮空的牌手应按 4 人计算，每位获得 3 轮轮空的牌手应按 8 人计算。
