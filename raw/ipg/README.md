## IPG 结构

IPG 包含 4 个主要章节：

1. **一般原则 (General Philosophy)** — 处罚定义、处罚应用、随机化牌库、倒回、牌叠
2. **游戏行动失误 (Game Play Errors)** — 遗漏触发、额外看牌、非公开牌张失误、再调度失误、违反游戏规则、未维护游戏状态
3. **比赛失误 (Tournament Errors)** — 迟到、外来协助、游戏进行过慢、套牌登记表问题、套牌问题、违反限制赛流程、违反交流原则、有记号的牌、未充分洗牌
4. **举止违背运动道德 (Unsporting Conduct)** — 轻微、严重、不当决定胜方、贿赂与赌博、攻击性举止、窃取比赛用品、拖延、作弊

## 处罚等级

| 处罚 | 英文 | 说明 |
|------|------|------|
| 警告 | Warning | 轻微违规，用于教育目的 |
| 一盘负 | Game Loss | 严重违规，立即结束当前对局 |
| 一局负 | Match Loss | 非常严重违规 |
| 取消资格 | Disqualification | 恶意违规或严重违背运动道德 |
