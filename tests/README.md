# MTG Skill 回归测试基准

22 道 Secrets of Strixhaven 规则测试题，用于验证 skill/agent 改造后规则回答能力是否退化。

---

## 文件结构

```
tests/
├── README.md          # 本文件
├── questions.md       # 22 道测试题（只含题目+选项，不含答案）
├── answers.md         # 标准答案+解析
└── logs/              # 历次测试记录
    ├── 2026-05-25-baseline.md
    └── YYYY-MM-DD-{tag}.md
```

---

## 快速开始

### 运行回归测试

对我说：

> **"跑回归测试"** — 自动读取 questions.md，调用当前 skill/agent 回答全部 22 题，生成测试报告到 logs/。
>
> **"跑回归测试，对比上次的"** — 同上，额外输出与上一次测试的 diff（哪些题上次对这次错，或反之）。
>
> **"对比 2026-05-25 和 2026-05-28 的测试结果"** — 对比任意两次历史测试记录。

### 查看结果

对我说：

> **"查看最近一次测试报告"** — 显示最新日志文件内容。
>
> **"查看测试历史"** — 列出 logs/ 下所有测试记录及摘要。
>
> **"Q7 为什么错了"** — 查看某道题的历史错误记录（跨所有日志统计）。

## 测试报告格式

每次测试生成一个 markdown 文件：`logs/YYYY-MM-DD-{tag}.md`

文件名中的 `{tag}` 由你指定（如 `dhet-phase1`、`before-refactor`、`after-verifier` 等），不指定则默认用 `run-序号`。

报告包含：

| 区块 | 内容 |
|------|------|
| 元信息 | 测试时间、skill 版本/分支、模型、tag |
| 总览 | 正确率、单选正确率、多选正确率 |
| 逐题结果 | Q1~Q22，每题：你的回答 vs 标准答案，判定 ✓/✗ |
| 错题分析 | 错题的详细对比（你选了什么，为什么错） |
| 与上次对比 | （如要求对比）哪些题状态变化 |
