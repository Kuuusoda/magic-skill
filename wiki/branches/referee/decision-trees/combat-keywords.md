# Combat Keywords 裁判决策树

涵盖飞行、延势、敏捷、警戒四个战斗相关 evergreen 关键词。

## 识别条件

以下任一情况触发此决策树：
- 题目涉及飞行生物的阻挡限制
- 题目涉及延势生物是否能阻挡飞行生物
- 题目涉及失去飞行后已宣告的阻挡是否合法
- 题目涉及生物是否受"召唤失调"影响
- 题目涉及敏捷/警戒生物的攻防条件

---

## 一、飞行 / 延势 (CR 702.9, 702.17)

### 检索路径

1. **CR 702.9b 飞行的阻挡限制** → 只有飞行/延势可以阻挡飞行
   - 攻击生物有飞行 → 阻挡生物**必须**有飞行或延势
   - 既没有飞行也没有延势的生物不能阻挡飞行生物
   - 这不影响攻击——飞行生物可以攻击任何牌手/鹏洛客/战役

2. **CR 702.17b 延势（Reach）** → 可以阻挡飞行生物
   - 延势的唯一功能：可以阻挡具有飞行的生物
   - 延势生物在阻挡非飞行生物时没有特殊规则
   - 延势不能攻击飞行——延势生物攻击时仍然是地面生物

3. **CR 506.4b 失去飞行与已宣告的阻挡** → 宣告后不会移除
   - 阻挡者已合法宣告阻挡飞行生物后，即使失去飞行/延势，阻挡仍然成立

### 常见陷阱

- **延势 = 飞行？** 不对。延势不能攻击飞行，只能**阻挡**飞行生物。
- **飞行生物被失去飞行后阻挡非法？** 不对。CR 506.4b — 宣告后阻挡者不会因攻击者特征改变而移出战斗。
- **延势+飞行 = 纯飞行？** 失去飞行但保留延势的生物仍可阻挡飞行生物。

## 二、敏捷 / 警戒 (CR 702.10, 702.20, 302.6)

### 检索路径

1. **CR 302.6 召唤失调** → 生物不能攻击或使用 {T} 费用
   - 如果牌手不是从该回合开始持续操控该生物
   - 不能攻击，不能使用含 {T} 的起动式异能
   - 不影响其他横置（如召集中的横置）

2. **CR 702.10b 敏捷（Haste）** → 无视召唤失调
   - 可以攻击（即使不是从回合开始操控）
   - 可以使用含 {T} 的起动式异能
   - 仍需未横置才能攻击

3. **CR 702.20b 警戒（Vigilance）** → 攻击不导致横置
   - 宣告攻击者时生物**必须未横置**（CR 508.1a）——警戒不改变此限制
   - 攻击后保持未横置，可以在攻击后使用 {T} 异能

4. **CR 508.1f 攻击导致横置** → 不是费用
   - 攻击**导致**横置，这不是宣告攻击的费用或条件
   - 警戒消除了这个"导致横置"的结果

### 常见陷阱

- **敏捷生物也需要未横置**才能攻击。敏捷只解决召唤失调。
- **警戒生物攻击后可以用 {T} 异能**。是的，这就是警戒的关键价值。
- **对方回合进场的敏捷生物不能攻击**。攻击只能在自己的战斗阶段宣告。
- **警戒让生物宣告攻击时不需要横置？** 不对。宣告时必须未横置，警戒只是攻击后不横置。

## 测试验证

- **题目**: 2/2 飞行攻击，对手只有 3/3 延势。能阻挡吗？
  → 期望结论: 能。延势可以阻挡飞行生物。

- **题目**: 刚进场的生物获得敏捷，能攻击吗？
  → 期望结论: 能。敏捷移除召唤失调，生物未横置就可以攻击。

- **题目**: 2/2 警戒生物攻击后，能用 {T} 产费吗？
  → 期望结论: 能。警戒攻击后不横置，可以在第二个行动阶段使用 {T} 异能。
