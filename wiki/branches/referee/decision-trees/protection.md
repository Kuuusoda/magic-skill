# Protection 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及"反...保护"的效果
- 题目涉及保护是否能防止某种效应
- 题目涉及保护与"不指定目标"效应（如告解高阶僧侣）的区别
- 题目涉及"反一切保护"的实际含义
- 题目涉及保护的 DEBT 四要素

## 检索路径（按优先级排序）

1. **CR 702.16b 保护的 DEBT 四要素** → 有保护异能的永久物/牌手：
   - **D**amage — 防止具有该特性的来源对其造成的**所有**伤害
   - **E**nchant / Equip — 不能被具有该特性的灵气结附，不能被具有该特性的武具佩带
   - **B**lock — 不能被具有该特性的生物阻挡
   - **T**arget — 不能被具有该特性的咒语或异能指定为目标

2. **CR 702.16c "反[特性]保护"** → 保护总是针对某一特性
   - "反红色保护" = 具有红色特性的来源
   - "反生物保护" = 具有生物卡牌类别的来源

3. **CR 702.16d "反[牌手]保护"** → 保护也可以针对牌手
   - "反该牌手保护" = 该牌手操控的来源

4. **CR 702.16e 保护的防止伤害** → 值得注意
   - 防止**所有**该特性来源的伤害，不只战斗伤害
   - 对伤害的防止不能跳过，即使牌手不想要

5. **CR 702.16f 保护的贴附限制** → 灵气/武具的取消
   - 如果灵气/武具**获得**了被保护的特性 → 从永久物上掉下（SBA 704.5m）

6. **CR 702.16g 保护的阻挡限制** → 有保护的生物不能被具有该特性的生物阻挡
   - 注意：这不能阻止有保护的生物**自己去阻挡**具有该特性的生物

7. **CR 702.16j "反一切保护"（Protection from everything）** → 最极端的保护
   - 防止所有来源的伤害
   - 不能被任何咒语/异能指定为目标
   - 不能被任何生物阻挡
   - 不能被任何灵气结附/武具佩带
   - **仍然可以被"不指定目标"的效应影响**（如告解高阶僧侣的-1/-1，或神之愤怒的消灭所有生物）

## 常见陷阱

- **陷阱**: 反红色保护的生物不能被神之愤怒消灭
  → **正确理解**: 神之愤怒不指定目标（只是"消灭所有生物"），也不造成伤害。所以反红色保护不能阻止。同理，告解高阶僧侣的-1/-1 效应也不指定目标，一样有效。

- **陷阱**: 反蓝色保护的生物不能被"回手目标永久物"指定，但可以被"将所有生物回手"（旋风）影响
  → **正确理解**: 旋风不指定目标，不受保护限制。

- **陷阱**: 有反生物保护的生物不能阻挡任何生物
  → **正确理解**: 反生物保护 = 不能被生物阻挡。这限制的是**谁可以阻挡它**，不限制它**可以去阻挡谁**。

- **陷阱**: 反黑色保护的生物被黑色生物阻挡，黑色生物造成战斗伤害
  → **正确理解**: 反黑色保护阻止所有来自黑色来源的伤害。黑色生物的战斗伤害被防止。但黑色生物**是否可以阻挡**反黑色保护的生物？不可以 — DEBT 的 B。

- **陷阱**: 保护 = 辟邪
  → **正确理解**: 保护远大于辟邪。辟邪只能阻止对手指定目标（= DEBT 的 T，仅限对手）。保护还防止伤害、阻止阻挡、防止结附。

## 测试验证

- **题目**: 反白色保护的生物被"放逐目标生物"（白色咒语）指定。会发生什么？
  → 期望检索: CR 702.16b DEBT-T
  → 期望结论: 不能指定为目标。如果玩家试图施放，目标选择是非法的，施放被倒回。

- **题目**: 反一切保护的生物在场。施放"所有生物得 -2/-2 直到回合结束"。反一切保护的生物会死吗？
  → 期望检索: CR 702.16j
  → 期望结论: 会（如果防御力 ≤2）。不指定目标，不造成伤害，不阻挡，不结附。保护不阻止。
