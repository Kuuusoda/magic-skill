# Targeting 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及咒语或异能"以...为目标"
- 题目涉及目标合法性的变化（目标离场、获得辟邪等）
- 题目涉及"咒语被反击" vs "咒语因目标非法而失效"（fizzle）
- 题目涉及改变目标或选择新目标的效应
- 题目涉及"任意一个目标"（any target）

## 检索路径（按优先级排序）

1. **CR 115.1 目标的定义** → 确认什么算"目标"
   - 只有使用了 "target" 一词的咒语/异能才具有目标
   - CR 115.10a: "受影响的物件不一定是目标"
   - "you" 不是目标（CR 115.10b）

2. **CR 115.2 合法目标** → 什么可以成为目标
   - 默认只有**战场上**的永久物可以是合法目标
   - 例外：咒语/异能指定可以目标其他区域（手牌、坟墓场等）或牌手
   - 堆叠上的咒语也可以是目标（反击咒语等）

3. **CR 115.4 "任意一个目标"（any target）** → 特殊目标语法
   - "any target" 只能是：生物、牌手、鹏洛客、战役
   - 不能选择非生物神器、结界、地等

4. **CR 115.5 自身目标限制** → 堆叠上的咒语/异能不能以自身为目标

5. **CR 115.3 同一目标多次选择** → 同一"target"词不能多次选同一目标
   - 但多段"target"可以各自选择同一目标（如"destroy target artifact and target land"可以目标同一个神器地）

6. **CR 601.2c 施放时选择目标** → 目标是施放过程的一部分
   - 触发式异能的目标在**进入堆叠时**选择（CR 603.3d）

7. **CR 608.2b 结算时检查目标合法性** → 结算时目标不再合法？
   - 如果**所有**目标都不合法 → 咒语/异能**从堆叠移除**（被反击不会触发"被反击时"的异能）
   - 如果至少有一个合法目标 → 正常结算，但对非法目标不产生效果

8. **CR 115.7 更改目标** → "change the target" vs "choose new targets"
   - "change the target": 必须将所有目标改为其他合法目标，否则一个都不改
   - "change a target": 只改一个
   - "choose new targets": 可以保留任意数量的原目标，新的必须合法且不使未改变的目标变成非法

## 常见陷阱

- **陷阱**: 目标获得辟邪后，咒语被"反击"
  → **正确理解**: 目标是施放时检查的。如果施放时目标合法，后来获得辟邪，结算时所有目标非法 → 咒语从堆叠移除（fizzle），不是被"反击"。触发"被反击时"的异能不会触发。

- **陷阱**: "选择"等于"目标"
  → **正确理解**: 除非牌面使用了"target"一词，否则不是目标。例如"choose a creature"不指定目标，不受辟邪影响。

- **陷阱**: "any target"可以选择任何东西
  → **正确理解**: CR 115.4 限制为生物、牌手、鹏洛客、战役四类。

- **陷阱**: 只有一个目标非法，多目标咒语整体失效
  → **正确理解**: CR 608.2b — 只要还有至少一个合法目标，咒语就正常结算，只是对非法目标不产生效果。

- **陷阱**: "destroy target creature. Its controller loses 3 life." 目标被牺牲后，牌手还失去3点生命
  → **正确理解**: 目标非法（生物已不在战场），但还有一个合法目标吗？没有了，这个咒语只有一个目标。所以不结算。但如果还有别的合法目标，就照样结算。

- **陷阱**: 灵气咒语的目标被牺牲后，灵气留在手上
  → **正确理解**: 灵气目标在所有目标中必须合法。如果目标不合法，灵气咒语从堆叠移除，进入坟墓场，不会回到手牌。

## 测试验证

- **题目**: 咒语"destroy target creature"的目标在结算前被牺牲。咒语会发生什么？
  → 期望检索: CR 608.2b
  → 期望结论: 目标非法，咒语从堆叠移除。不结算任何效果。

- **题目**: "deal 3 damage to any target"可以选择非生物神器吗？
  → 期望检索: CR 115.4
  → 期望结论: 不可以。any target 只能是生物、牌手、鹏洛客、战役。
