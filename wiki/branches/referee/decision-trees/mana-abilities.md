# Mana Abilities 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及某个异能是否为法术力异能（是否使用堆叠）
- 题目涉及法术力异能与触发式异能的区别
- 题目涉及"产生法术力"和"目标"的关系
- 题目涉及启动法术力异能是否可以被响应
- 题目涉及息法符等与法术力异能的互动

## 检索路径（按优先级排序）

1. **CR 605.1a 法术力异能的定义** → 三个条件同时满足
   - a) 是启动式异能或触发式异能
   - b) 能**产生法术力**（不是"增加法术力到法术力池"）
   - c) **不指定目标**（CR 115）
   - 三个条件全部满足 = 法术力异能

2. **CR 605.1b 法术力异能不使用堆叠** → 立即结算
   - 启动法术力异能不能被响应
   - 触发式法术力异能不能被响应
   - 触发式法术力异能触发时直接结算（不进入堆叠，不等待优先权）

3. **CR 605.3b 启动法术力异能** → 支付费用时启动
   - 可以在施放咒语或启动异能的**支付费用步骤**中启动法术力异能
   - 不需要在支付前启动——费用可以同步解决

4. **CR 605.4a 不是法术力异能** → 产生法术力但有其他条件
   - 指定目标的异能不是法术力异能（即使它产生法术力）
   - 不是启动式/触发式的异能不是法术力异能（静止式异能不能是法术力异能）
   - 忠诚异能不是法术力异能（即使它产生法术力且不指定目标）

5. **CR 106.4 法术力池** → 未被使用的法术力
   - 法术力产生后保留在法术力池中
   - 每步骤/阶段结束时，未使用的法术力消失，牌手失去等量生命（法术力灼伤已被废除，但现在没有灼伤了——只需注意法术力会消失）

## 常见陷阱

- **陷阱**: 所有产生法术力的异能都不使用堆叠
  → **正确理解**: 只有**法术力异能**不使用堆叠。如果产生法术力的异能指定目标（如息法符），它不是法术力异能，使用堆叠，可以被响应。

- **陷阱**: "增加一点任意颜色的法术力"总是不使用堆叠
  → **正确理解**: 取决于来源。如果来源是地牌（横置产费）→ 是法术力异能。如果来源是鹏洛客的忠诚异能 → 不是法术力异能。

- **陷阱**: 鹏洛客的"+1: 加 {G}"不使用堆叠
  → **正确理解**: 忠诚异能永远不是法术力异能（CR 606.3）。即使它产生法术力且不指定目标。

- **陷阱**: 触发式法术力异能可以响应
  → **正确理解**: CR 605.1b 明确触发式法术力异能不进入堆叠，直接结算。例如：领土异能（每当 X 进入战场时加 Y 法术力）如果符合 605.1a 的三条件，就是触发式法术力异能，直接结算。

- **陷阱**: 触发式异能产生法术力 = 法术力异能
  → **正确理解**: 还必须满足"不指定目标"。如果触发式异能指定目标（如"对目标牌手造成 2 点伤害并加 {R}{R}"），则不是法术力异能。

## 测试验证

- **题目**: 死亡仪式祭师（Deathrite Shaman）的第一个异能："{T}: 放逐目标坟墓场中的一张地牌，加一点任意颜色的法术力。"这是法术力异能吗？
  → 期望检索: CR 605.1a-c
  → 期望结论: 不是。它指定了目标（坟墓场中的地牌）。不满足 605.1a 的条件 c。使用堆叠，可以被响应。

- **题目**: 天堂鸟的异能："{T}: 加一点任意颜色的法术力。"可以被扼（Stifle）反击吗？
  → 期望检索: CR 605.1b
  → 期望结论: 不可以。这是法术力异能，不使用堆叠，不能被扼选择为目标。
