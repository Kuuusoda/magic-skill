# Targeting Restrictions 裁判决策树

涵盖辟邪、帷幕、守护三种防止/限制被指定为目标的机制。

## 识别条件

以下任一情况触发此决策树：
- 题目涉及辟邪或帷幕对指定目标的影响
- 题目涉及守护异能的触发和支付
- 题目涉及"不指定目标"效应是否绕过这些机制
- 题目涉及三种机制的关键区别

---

## 一、辟邪 Hexproof (CR 702.11)

### 检索路径

1. **CR 702.11a** → 不能被**对手**的咒语或异能指定为目标
   - 自己可以指定自己有辟邪的永久物
   - 对手的辟邪永久物对手自己可以指定

2. **CR 702.11b** → 目标合法性在施放/触发时检查
   - 已经施放的咒语，目标后获得辟邪 → 结算时非法 → fizzle
   - 对手试图以辟邪生物为目标施放咒语 → 非法施放，倒回

## 二、帷幕 Shroud (CR 702.18)

### 检索路径

1. **CR 702.18a** → 不能被**任何**咒语/异能指定为目标
   - **包括自己**——与辟邪的关键区别
   - 帷幕生物不能佩带武具（佩带指定目标）

## 三、守护 Ward (CR 702.21)

### 检索路径

1. **CR 702.21a** → 守护是触发式异能
   - 永久物被对手的咒语/异能指定为目标时触发
   - 触发后该咒语/异能的操控者可以支付 [费用]
   - 不支付 → 该咒语/异能**被反击**（CR 702.21b）

2. **CR 702.21c 多个守护实例** → 各自独立触发
   - 每个守护异能独立触发，各需支付一次
   - **全部**未支付才会被反击

3. **CR 702.21d 无法支付** → 自动不支付，咒语被反击

4. **CR 702.21e 不能被反击的咒语** → 守护不支付也反击不了

## 三者对比

| | 辟邪 | 帷幕 | 守护 |
|---|---|---|---|
| 对手能指定目标？ | 不能 | 不能 | 能（触发守护） |
| 自己能指定目标？ | 能 | 不能 | 能 |
| 是触发式异能？ | 否（静止式） | 否（静止式） | 是 |
| 支付费用可绕过？ | 不能 | 不能 | 能 |
| 非目标效应受影响？ | 否 | 否 | 否 |

## 常见陷阱

- **"所有生物得 -2/-2"对辟邪/帷幕有效** → 不指定目标，完全有效。
- **"目标牌手牺牲一个生物" → 辟邪生物也会死** → 目标是牌手，不是生物。
- **守护{0} ≠ 没有守护** → 仍然触发，对手需选择支付{0}或不支付。
- **通过非施放方式进场的灵气可贴附帷幕生物** → CR 303.4f — 不指定目标，只"选择"贴附对象。
- **帷幕 ≠ 辟邪** → 帷幕连自己都不能指定，辟邪只限制对手。

## 测试验证

- **题目**: 对手的辟邪生物，我可以用"消灭目标生物"吗？
  → 期望结论: 不可以。辟邪阻止对手指定目标。

- **题目**: 守护 {2} 的生物，对手支付 {2} 后咒语正常结算吗？
  → 期望结论: 是的。守护不阻止指定目标，支付费用后咒语正常结算。

- **题目**: 有帷幕的生物，我能用自己的灵气结附吗？
  → 期望结论: 不能施放目标为帷幕生物的灵气咒语。但可以直接放进战场的灵气（CR 303.4f）可以贴附——因为它不指定目标。
