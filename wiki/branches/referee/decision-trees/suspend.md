# Suspend 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及延缓异能的触发条件
- 题目涉及"从手牌"的限制——不能从其他区域延缓
- 题目涉及延缓牌的施放时机和费用
- 题目涉及延缓牌被移除最后一个时间指示物后是否可以使用
- 题目涉及延缓与"不支付法术力费用"的互动

## 检索路径（按优先级排序）

1. **CR 702.62a 延缓的起动** → 只能从手牌
   - "延缓 N — [费用]" = 如果你能从手牌施放此牌，你可以支付 [费用] 并将其放逐，上面有 N 个时间指示物
   - **只能从手牌**延缓（CR 702.62a 明确"You may exile this card from your hand"）
   - 不能从其他区域（如坟墓场、放逐区、牌库顶）延缓

2. **CR 702.62b 延缓牌的时间指示物移除** → 维持步骤触发
   - 在维持开始时，如果该牌在放逐区且有延缓 → 移除一个时间指示物
   - 这是触发式异能，使用堆叠

3. **CR 702.62c 最后一个时间指示物移除** → 施放触发
   - 当**最后一个**时间指示物被移除时 → 触发异能
   - 该异能结算时 → 牌手**可以**施放该牌（不支付法术力费用）
   - 如果 X 在法术力费用中，而你"不支付法术力费用"——X 只能为 0（CR 107.3b）
   - 时机限制仍然适用：法术只能在你的行动阶段施放（除非有闪现）
   - 如果牌手选择不施放 → 牌留在放逐区（继续没有时间指示物，不会再触发）

4. **CR 702.62d 施放延缓牌** → 与正常的施放时机相同
   - 施放延缓牌必须遵守正常的时机限制
   - 如果是法术牌 → 只能在你的行动阶段施放
   - 如果有闪现 → 任何时机都可以

5. **CR 702.62e 延缓的效果** → 只有一次施放机会
   - 最后一个指示物移除并触发异能后，如果牌手选择不施放或不能施放 → 牌永久留在放逐区
   - 施放后正常结算（如果被反击则进坟墓场；结算后正常进入其区域）

## 常见陷阱

- **陷阱**: 可以从坟墓场或放逐区延缓牌
  → **正确理解**: CR 702.62a — 延缓只能从**手牌**起动。这是最常见的裁判误解之一。

- **陷阱**: 延缓牌在"不支付法术力费用"下施放，X 可以任意选择
  → **正确理解**: CR 107.3b — 不支付法术力费用且费用中含 X 时，X 只能选择 0。

- **陷阱**: 最后一个时间指示物移除后，必须立即施放，不能等待
  → **正确理解**: 最后一个指示物移除触发异能，异能进入堆叠，结算时牌手**可以**选择施放。如果时机不合法（如敌方法术牌在你的回合外），就不施放，牌留在放逐区。

- **陷阱**: 延缓牌在放逐区，可以被"从放逐区施放"的效应施放
  → **正确理解**: 可以。延缓牌的施放并不依赖延缓本身——如果有其他效应允许从放逐区施放，就可以施放（但必须支付法术力费用，因为延缓的不支付只适用于最后一个指示物移除时的触发）。

## 测试验证

- **题目**: 延缓牌已在放逐区，牌手启动异能试图"从放逐区施放该牌"（如通过激情博士普靠匝斯）。可以不支付费用施放吗？
  → 期望检索: CR 702.62
  → 期望结论: 可以施放，但**必须支付**法术力费用。"不支付法术力费用"只在最后一个时间指示物移除的延迟触发中适用。

- **题目**: 从坟场使用返照施放牌，可以同时用延缓吗？
  → 期望检索: CR 702.62a
  → 期望结论: 不可以。延缓只能从手牌起动。返照在施放时在坟墓场中。两者不兼容。
