# Tokens 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及衍生物的创建或消失
- 题目涉及衍生物改变区域后会发生什么
- 题目涉及衍生物的复制
- 题目涉及衍生物是否为"牌"的判定
- 题目涉及"populate"（增殖衍生物）或衍生物操控者

## 检索路径（按优先级排序）

1. **CR 111.1 衍生物的定义** → 衍生物不是牌
   - 衍生物是由咒语/异能产生、放置在战场上的标记
   - 衍生物**不是牌**（即不触发"每当一张牌..."的异能）
   - 衍生物可以是任何永久物类别

2. **CR 111.3 衍生物的操控者** → 创建者=操控者
   - 由谁操控的效应创造的衍生物，由谁操控
   - 例如："在目标牌手操控下放置一个 1/1 衍生物"由该牌手操控

3. **CR 111.4 衍生物的特征** → 咒语/异能定义其特征
   - 基础特征由创造效应指定（颜色、类别、力量/防御力等）
   - 如果未指定，按以下默认：
     - a) 衍生物的名称与其所有生物类别相同（如"精灵/战士"的名称为"精灵 战士"）
     - b) 法术力费用为 0
     - c) 法术力值为 0
     - d) 是衍生物
     - e) 如果未指定，不一定总是生物

4. **CR 111.5 衍生物复制** → 复制永久物为衍生物
   - 如果创造效应说"创造一个衍生物，复制..."，衍生物获得原始的特征
   - 衍生物的特征 = 复制的原始物件在结算时的可复制值

5. **CR 111.7 衍生物进入非战场区域** → 关键规则
   - 衍生物进入手牌、坟墓场、牌库、放逐区 → 可以到达该区域
   - 但在下一次 SBA 检查时**消失**（704.5d）
   - 衍生物在消失前会触发进入该区域的触发式异能

6. **CR 111.8 衍生物离开战场** → 进入其他区域后不再回到战场
   - 如果衍生物跃离（phase out），不会消失，会跃回
   - 衍生物被弹回手牌 → 进入手牌，触发相关异能，然后消失

7. **CR 111.10 "populate"（衍生物增殖）** → 创建一个已有衍生物的复制
   - 选择一个你操控的衍生物，创建该衍生物的复制

8. **Token 创建被替代为多个 token**
   - 如果一个效应要创建一个 token，但替代性效应把它改为创建多个同样的 token，后续“对该 token 做某事”的指示通常应用于由该事件创建的所有 token。
   - 仍需检查具体英文措辞；若后续指示明确只影响“one of them”，则按牌面执行。

## 常见陷阱

- **陷阱**: 衍生物死亡后进入坟墓场，不会触发"当生物死去时"的异能
  → **正确理解**: 衍生物可以进入坟墓场，并触发死亡异能。之后在 SBA 检查时消失。它只是不能长期存在于非战场区域。

- **陷阱**: 衍生物被弹回手牌后不触发"当生物离开战场时"的异能
  → **正确理解**: 衍生物离开战场时触发相关异能，进入手牌后触发"进入手牌时"的异能，然后在 SBA 检查时消失。

- **陷阱**: 衍生物是牌
  → **正确理解**: 衍生物不是牌。涉及"牌"的效应不适用于衍生物（如"放逐目标牌"不能选择衍生物，因为它不在战场上）。在战场上时衍生物是永久物，可以作为目标。

- **陷阱**: 衍生物跃离后消失
  → **正确理解**: 跃离（phased out）的衍生物不会触发 704.5d。衍生物跃离后仍存在，不会消失。

- **陷阱**: 衍生物复制品的法术力值与原始相同
  → **正确理解**: 衍生物复制的法术力值 = 原始的可复制值中的法术力费用。但如果效应说"创造一个 1/1 衍生物，它是...的复制"，效应可能修改力量和防御力。

- **陷阱**: 新创建出的 token 的替代性效应可以继续加倍本次创建
  → **正确理解**: 替代性效应必须在事件发生前存在。新 token 的静止式异能只能影响未来事件。

## 测试验证

- **题目**: 一个 2/2 灵俑衍生物死亡。它触发了"当灵俑死去时"的异能吗？
  → 期望检索: CR 111.7, 111.1
  → 期望结论: 是的。衍生物进入坟墓场，触发了死亡异能，然后在下一次 SBA 检查时消失。

- **题目**: 一个衍生物被放逐，会怎样？
  → 期望检索: CR 111.7, 704.5d
  → 期望结论: 衍生物进入放逐区，触发相关异能，然后在 SBA 检查时消失。不能从放逐区再回来。
