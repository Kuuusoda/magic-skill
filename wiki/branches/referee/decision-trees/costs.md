# Costs 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及施放咒语的费用计算
- 题目涉及额外费用（增幅、增幅等）与费用减少的互动
- 题目涉及替代性费用（返照、不支付法术力费用）
- 题目涉及"不能支付"某类法术力的情形
- 题目涉及费用增加/减少在总费用计算中的顺序

## 检索路径（按优先级排序）

1. **CR 601.2f 总费用计算顺序** → 关键规则
   - a) 确定替代性费用（如返照、延缓，只能选一个）或是否使用不支付
   - b) 确定额外费用（增幅、购回等）和选择性额外费用
   - c) 增加费用（税效应，如瑟班守护者莎莉亚）
   - d) 减少费用（如虚色伏击客、精雅大剑）
   - e) 三定法球 — 在费用减少后应用，但不超过总费用
   - 最终结果不能为负

2. **CR 118.3 支付费用** → 以任意顺序支付各费用部分
   - 横置地产生法术力的行为是**法术力异能**（CR 605），不使用堆叠

3. **CR 118.5 法术力费用中的 X** → X 是施放咒语的一部分
   - 牌手先宣告 X 值，再计算总费用
   - 费用增加/减少**不影响 X 的宣告**（CR 601.2b）

4. **CR 118.7 必须支付费用** → 不能支付法术力？咒语施放非法
   - 如果有其他效应使得不能支付法术力，则施放非法 → 倒回（CR 728）

5. **CR 118.8 不得支付法术力的情形** → 来源不能产生某色法术力时不能支付
   - 如果费用要求某色法术力且来源不能产生该色 → 不能支付

6. **CR 118.9 费用中的生命支付** → 不能支付比现有更多的生命
   - 生命支付是费用的一部分，减少生命是结果而非额外费用

7. **CR 601.2h 支付总费用** → 启动法术力异能后一次性支付
   - 支付时可以横置未召唤失调的生物（召集等）

## 常见陷阱

- **陷阱**: 增幅费用受费用减少影响
  → **正确理解**: 增幅是额外费用（step b），费用减少在 step d 应用。两者都参与计算。例如：费用 {2}{R} 增幅 {1}，有 1 点减费 → 总费用 {2}{R}（{2}{R} + {1} - {1}）。

- **陷阱**: "不支付法术力费用"的法术力费用为 0，所以 X=0
  → **正确理解**: CR 107.3b — 不支付法术力费用且费用中含 X 时，X 只能选择 0。

- **陷阱**: 三定法球让所有咒语变成 {3}
  → **正确理解**: 三定法球在费用减少**之后**应用。如果减少后费用小于 {3}，改为 {3}；如果已经 ≥{3}，三定法球无效。三定法球本身也会被费用减少影响。

- **陷阱**: 费用增加和减少互相抵消
  → **正确理解**: 顺序是固定的：替代 → 额外 → 增加 → 减少 → 三定法球。不能因为"效果相等"就跳过步骤。

## 测试验证

- **题目**: 一个 {2}{G} 咒语，受到 2 点减费（如虚色伏击客），三定法球在场。总费用是多少？
  → 期望检索: CR 601.2f
  → 期望结论: 仍是 {3}。减费后为 {G}，小于 {3}，三定法球改为 {3}。

- **题目**: 增幅 {2} 的咒语，有 2 点额外增加（税）和 1 点减费。总费用怎么算？
  → 期望检索: CR 601.2f
  → 期望结论: {mana} + {2}(增幅) + {2}(增加) - {1}(减少) = {mana} + {3}

7. **CR 702.66a 掘穴（Delve）** → 以放逐坟场牌替代支付 {1}
   - 在支付总费用时（CR 601.2h），可以放逐坟墓场中的牌代替支付 {1}
   - 掘穴**不是**费用减少，不是替代性费用——发生在支付步骤
   - 只能替代无色法术力（{1}），不能替代 {G}、{R} 等有色法术力
   - 放逐不进入堆叠，对手不能响应掘穴的放逐

- **陷阱**: 增幅费用受费用减少影响
