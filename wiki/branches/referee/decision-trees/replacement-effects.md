# 替代性效应裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 牌面包含 "instead" / "改为"
- 牌面包含 "skip" / "略过"
- 牌面包含 "enters with..." / "enters as..." / "须...进场"
- 题目涉及伤害被转移、事件被替代、消灭被防止
- 需要判断多个替代性效应的生效顺序

## 检索路径（按优先级排序）

1. **CR 614.1 替代性效应的定义** → 确认是否为替代性效应
   - **关键词**: "instead" / "改为" / "skip" / "略过"
   - **进场格式**: "enters with..." / "enters as..." / "enters..."
   - **与防止性效应的区别**: 替代性效应改变事件本身，防止性效应阻止事件发生（CR 615）

2. **CR 614.4 存在时机** → 确认替代性效应是否已存在
   - 替代性效应必须在**事件发生之前**已存在
   - 不能在事件发生后"回溯"替代

3. **CR 614.5 自我限制** → 确认替代性效应不会反复引发
   - 一个替代性效应**只有一次机会**对一个事件生效
   - 例如：两个"造成伤害改为两倍"的异能，2点伤害 → 第一个改为4点 → 第二个改为8点（不是无限加倍）

4. **CR 614.6 事件替代的后果** → 确认被替代的事件从未发生
   - 被替代的事件**从未发生过**
   - 被更改的事件**可能触发异能**
   - 如果被更改的事件包含无法执行的指示，**忽略无法执行的部分**

5. **CR 614.12 ETB 替代性效应** → 确认进场时的特征
   - 检查永久物将存在于战场上的**特征**
   - 考虑：影响进场的替代性效应 + 进场后生效的静止式异能 + 已存在的持续性效应
   - 这决定了 ETB 替代性效应是否生效

## 常见陷阱

- **陷阱**: 替代性效应可以回溯改变已发生的事件
  → **正确理解**: CR 614.4 明确禁止回溯。必须在事件发生前已存在。

- **陷阱**: 多个相同的替代性效应会无限叠加
  → **正确理解**: CR 614.5。每个替代性效应只有一次机会。两个"加倍"异能 = 2×2=4倍，不是无限。

- **陷阱**: 被替代的事件仍然"发生"并触发相关异能
  → **正确理解**: CR 614.6。被替代的事件**从未发生过**。但**被更改的事件**可能触发异能。例如：伤害被替代为抓牌，抓牌可能触发"当你抓牌时"的异能。

- **陷阱**: 重生可以在消灭发生后使用
  → **正确理解**: CR 614.8。重生是替代消灭的效应，必须在消灭发生前已创建。消灭后再重生为时已晚。

- **陷阱**: 具有"进场时带指示物"的替代性效应的生物，其进场触发的异能结算时指示物已经存在
  → **正确理解**: 是的。ETB 替代性效应在进场时就已经应用，因此当"进场触发"进入堆叠时，指示物已经在永久物上了。

- **陷阱**: 两个替代性效应同时生效时，由对手选择顺序
  → **正确理解**: 受影响物件的**操控者**（或受影响牌手）选择替代性效应的生效顺序。见 CR 616.1。

## 测试验证

- **题目**: 两个"造成伤害改为两倍"的异能在场，一个生物造成2点伤害，最终伤害是多少？
  → 期望检索: CR 614.5
  → 期望结论: 8点。第一个改为4点，第二个改为8点。不是4点，也不是无限。

- **题目**: 一个具有"进场时带+1/+1指示物"替代性效应的生物进场，同时有一个"每当一个生物进场时"触发。触发结算时该生物有指示物吗？
  → 期望检索: CR 614.12
  → 期望结论: 有。ETB 替代性效应在进场时就已应用。
