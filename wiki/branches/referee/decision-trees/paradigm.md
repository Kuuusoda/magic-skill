# Paradigm 裁判决策树

## 识别条件

- 牌面包含 `Paradigm`
- 题目涉及某咒语第一次以该名称结算后，在未来主阶段创建复制品
- 题目涉及复制品结算、原牌离开游戏、或放逐区复制品消失

## 检索路径

1. **CR 702.192a Paradigm 定义**
   - Paradigm 代表两个咒语异能，其中一个创建延迟触发式异能。
   - 若这是你操控的该名称咒语本盘第一次结算，则在本盘剩余每个你的战斗前行动阶段开始时，在放逐区创建该物件的复制品，且你可以不支付法术力费用施放该复制品。
   - 然后放逐该咒语。

2. **CR 707.10 复制咒语**
   - 复制咒语或异能会把复制品放入堆叠；复制品可以是没有实体牌代表的咒语。

3. **CR 704.5e / 707.10a 复制品消失**
   - 复制品进入非堆叠区域后通常会在状态动作中消失。

4. **延迟触发独立性**
   - 一旦 Paradigm 创建了未来主阶段的延迟触发，该触发不依赖此前结算的复制品继续存在。
   - 原牌的拥有者离开游戏或原牌离开某区域，不会取消已经创建的延迟触发，除非规则另有说明。

## 常见陷阱

- **陷阱**: Paradigm 只对由实体牌代表的咒语生效。
  → **正确理解**: 规则关心“你操控的该名称咒语结算”，咒语复制品也可以满足。

- **陷阱**: 同名实体牌之后结算会再创建第二个未来触发。
  → **正确理解**: 只在你操控的该名称咒语本盘第一次结算时创建。

- **陷阱**: 复制品消失后，未来主阶段的 Paradigm 触发也消失。
  → **正确理解**: 已创建的延迟触发独立存在。
