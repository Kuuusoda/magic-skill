# Equipment / Auras 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及武具的佩带时机和目标
- 题目涉及灵气贴附于非法永久物或失去贴附目标
- 题目涉及闪现佩带 vs 正常佩带
- 题目涉及武具生物或灵气生物的规则
- 题目涉及武具/灵气与帷幕、辟邪、保护的互动

## 检索路径（按优先级排序）

1. **CR 301.5 武具的佩带** → 起动式异能
   - "佩带 [费用]" = "[费用]：将此永久物贴附于目标由你操控的生物。只能于法术力时机起动。"
   - 佩带是起动式异能，指定目标生物
   - 只能在你能施放法术的时机使用（你的行动阶段，堆叠为空，有优先权）

2. **CR 301.5c 佩带后武具保持贴附** → 即使不合法也不自动脱落
   - 佩带后，除非被其他效应解除，否则武具持续贴附于同一生物
   - 如果生物获得帷幕 → 佩带已贴附，不受影响。但如果重新佩带，则必须合法（帷幕不能成为目标）
   - 如果生物不再是生物 → 武具在 SBA 检查时脱落（301.5d, 704.5m）

3. **CR 303.4 灵气的贴附** → 作为咒语施放时贴附
   - 灵气咒语需要目标（贴附的对象）
   - 灵气咒语结算时，进入战场贴附于该目标
   - 如果目标在结算前非法 → 灵气咒语从堆叠移除，进入坟墓场

4. **CR 303.4c 灵气贴附于非法永久物** → SBA 置入坟墓场
   - 如果灵气的贴附对象不再满足灵气的"enchant [条件]" → SBA 704.5m 将灵气置入坟墓场
   - 例如：反黑保护的生物上贴附黑色灵气 → 灵气置入坟墓场

5. **CR 303.4f 不通过施放进战场的灵气** → 选择贴附对象
   - 如果效应直接将灵气放进战场（如"从坟墓场将目标灵气放进战场"）→ 灵气不指定目标，直接选择贴附对象
   - 这**绕过**辟邪和帷幕（因为不是指定目标）
   - 但仍需满足贴附的合法性条件

6. **CR 301.6 武具生物** → 武具也是生物时
   - 武具同时是生物时 → 不能贴附于其他生物
   - 它仍然是武具，可以被"消灭目标神器"等效应影响

## 常见陷阱

- **陷阱**: 佩带是法术时机，回合结束无法佩带
  → **正确理解**: 是的。佩带默认只能在你的行动阶段+堆叠为空时使用。

- **陷阱**: 生物被消灭后，贴附的武具保留在战场上
  → **正确理解**: 是的。武具是独立的永久物，被佩带的生物死亡后，武具不跟随进入坟墓场，留在战场上（成为未贴附的武具）。

- **陷阱**: 不通过施放进场的灵气仍然"指定目标"
  → **正确理解**: CR 303.4f — 直接进场的灵气只是"选择"贴附对象，不是"指定目标"。可以贴附于辟邪或帷幕的永久物。

- **陷阱**: 灵气咒语的目标在结算前被牺牲，灵气回到手牌
  → **正确理解**: 不回到手牌。CR 608.2b — 目标非法，咒语从堆叠移除，进入坟墓场。

## 测试验证

- **题目**: 对手的帷幕生物可以被佩带吗？
  → 期望检索: CR 301.5, 702.18a
  → 期望结论: 不能。佩带是起动式异能，指定目标。帷幕生物不能被任何咒语/异能指定为目标。

- **题目**: 灵气从坟墓场被直接放进战场。能贴附在辟邪生物上吗？
  → 期望检索: CR 303.4f
  → 期望结论: 能。直接进场的灵气不指定目标，辟邪不受保护。
