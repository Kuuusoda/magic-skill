# State-Based Actions 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及生物"死亡"的原因（致命伤害 vs 消灭 vs 防御力≤0）
- 题目涉及传奇规则、普世规则、灵气/武具贴附合法性
- 题目涉及 +1/+1 和 -1/-1 指示物互相抵消
- 题目涉及中毒、生命≤0、空牌库抓牌导致的输掉游戏
- 题目涉及衍生物离开战场、复制品在非堆叠/非战场区域
- 需要判断某事件是否触发"当...死去时"异能

## 检索路径（按优先级排序）

1. **CR 704.3 检查时机** → 确认 SBA 何时执行
   - 每次有牌手将获得优先权时
   - 咒语/异能结算完毕后
   - **不使用堆叠**，不能响应
   - SBA 检查会重复直到没有新的 SBA 需要执行

2. **CR 704.4 结算过程中的状态变化** → SBA 不关心中间状态
   - SBA 不关注咒语/异能**结算过程中**发生的状态变化
   - 只在结算完毕后检查
   - 例如：弃掉手牌再抓牌的过程中，生物防御力短暂为0不会导致死亡

3. **CR 704.5a 生命≤0** → 牌手输掉游戏

4. **CR 704.5f 防御力≤0** → 生物置入坟墓场（重生无法替代）
   - 注意与 704.5g 的区别：防御力≤0 是"置入坟墓场"，不是"消灭"
   - 不灭无法防止防御力≤0 导致的死亡

5. **CR 704.5g 致命伤害（标记伤害≥防御力）** → 生物被消灭
   - 重生**可以**替代；不灭**可以**防止
   - 标记的伤害在清除步骤才移除（CR 514.2）

6. **CR 704.5h 死触伤害** → 受到死触来源伤害的生物被消灭
   - 自从上次 SBA 检查后受到即可，无论伤害多少
   - 重生可以替代

7. **CR 704.5j 传奇规则** → 同一牌手操控两个或更多同名传奇永久物
   - 该牌手选择保留一个，其余置入坟墓场
   - **不是牺牲，不是消灭** — 不触发"牺牲时"异能，不灭无法防止
   - 触发"当生物死去时"的异能（进入了坟墓场）
   - **鹏洛客**: 鹏洛客类别（如"Jace"）在传奇规则判定时作为名称（CR 306.7）
   - 两个不同牌手各操控一个同名传奇永久物**不触发**传奇规则
   - **复制品**：大多数复制效应保留传奇超类别 → 可能触发传奇规则

8. **CR 704.5m 灵气不合法** → 未贴附或贴附于不合法物件的灵气置入坟墓场

9. **CR 704.5q +1/+1 和 -1/-1 指示物抵消** → N对抵消，N为较少者

10. **CR 704.5d 衍生物在非战场区域** → 衍生物消失

## 常见陷阱

- **陷阱**: 防御力≤0 的生物被"消灭"
  → **正确理解**: CR 704.5f 使用"置入坟墓场"，不是"消灭"。不灭不能防止，重生不能替代。

- **陷阱**: 两个传奇永久物同时在场，对手帮你选择牺牲哪个
  → **正确理解**: 传奇规则是"选择并置入坟墓场"，不是"牺牲"。由操控者自己选择保留哪个。

- **陷阱**: 致命伤害导致的消灭在伤害造成时立即发生
  → **正确理解**: 伤害标记后，在下一次 SBA 检查时才消灭。中间可能有响应窗口。

- **陷阱**: 具有不灭的生物受到致命伤害后会死
  → **正确理解**: 不灭的生物忽略 704.5g 的致命伤害检查。但-1/-1指示物将防御力减至0以下仍然会死（704.5f）。

- **陷阱**: SBA 在咒语结算过程中也会检查
  → **正确理解**: CR 704.4 明确 SBA 不关注结算过程中的状态。只看结算前后的快照。

- **陷阱**: 传奇规则是"牺牲"多余的传奇永久物
  → **正确理解**: 传奇规则是"选择并置入坟墓场"。不是牺牲，不触发牺牲相关异能。

- **陷阱**: 同名传奇由两个不同牌手操控也会触发传奇规则
  → **正确理解**: CR 704.5j 只说"同一牌手操控两个或更多"。不同牌手各一个不触发。

## 测试验证

- **题目**: 一个4/4不灭生物被造成4点伤害，然后得到一个-4/-4的效应。它会死吗？
  → 期望检索: CR 704.5f vs 704.5g
  → 期望结论: 会死。防御力变为0（704.5f），不是致命伤害（704.5g），不灭不能防止。

- **题目**: 同一个牌手操控两个同名传奇永久物，会发生什么？
  → 期望检索: CR 704.5j
  → 期望结论: 该牌手选择一个保留，另一个直接置入坟墓场。不触发牺牲异能，不被不灭保护。
