# Convoke 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 牌面包含 "Convoke" 关键字
- 题目涉及横置生物来支付咒语费用
- 题目涉及费用增减效应（如 Thalia、Goblin Electromancer）与召集的互动
- 需要判断某个生物是否可以用来召集支付特定颜色的费用

## 检索路径（按优先级排序）

1. **CR 702.51a Convoke 定义** → 确认核心机制
   - **异能类型**: 静止式异能，仅在咒语在堆叠上时生效
   - **有色费用**: 可以横置一个由你操控的未横置的**该色**生物来支付该有色法术力
   - **一般费用**: 可以横置一个由你操控的未横置的**任意颜色**生物来支付每一点一般法术力
   - 生物必须**未横置**才能用来召集

2. **CR 702.51b 费用计算时机** → 确认召集与费用增减的互动
   - 召集**不是**额外费用或替代性费用
   - 召集仅在咒语的**总费用被确定之后**生效
   - 顺序：确定 mana cost → 应用费用增减（如 Thalia +1、Electromancer -2）→ 确定总费用 → 应用召集
   - 召集支付的是**总费用中的法术力**，不是原始 mana cost

3. **CR 702.51c "convoked" 的定义**
   - 用生物横置支付费用即称为该生物"召集"了该咒语
   - 召集是支付费用的一部分，对手不能响应你横置生物的动作

4. **CR 702.51d 多个召集**
   - 同一个咒语上的多个召集异能**无意义**（redundant）

## 常见陷阱

- **陷阱**: 召集可以支付原始 mana cost，不受费用增减影响
  → **正确理解**: 召集支付的是**总费用**（total cost），已经包含了费用增减效应的影响。见 CR 702.51b 示例。

- **陷阱**: 具有召集的咒语被 counter 后，已横置的生物重置
  → **正确理解**: 已横置的生物保持横置状态。召集只是支付费用的方式，不是替代性效应。

- **陷阱**: 多色生物可以支付任意颜色的费用
  → **正确理解**: 多色生物只能支付其**拥有的颜色之一**对应的有色费用。例如，红绿双色生物可以支付 {R} 或 {G}，但不能支付 {U}。

- **陷阱**: 召集可以用于支付额外费用（如 Kicker）
  → **正确理解**: 召集只适用于咒语的**总费用中的法术力部分**。如果额外费用中包含法术力，召集也可以用来支付（因为额外费用是总费用的一部分）。但如果额外费用是非法术力成本（如牺牲生物），召集不能替代。

- **陷阱**: 对手可以响应召集横置生物的动作
  → **正确理解**: 召集发生在**支付总费用**的过程中（CR 601.2h），此时牌手没有优先权，对手无法插入动作。

- **陷阱**: 横置生物召集后，该生物的异能（如"横置：加费"）可以同时起动
  → **正确理解**: 召集是支付费用的一部分，不是起动式异能。但如果需要支付剩余费用，可以在召集之前起动 mana abilities。

## 测试验证

- **题目**: 施放费用 {3}{W}{W} 且具有召集的咒语，场上有 Thalia（非生物咒语费用+1），可以用几个生物召集？
  → 期望检索: CR 702.51b
  → 期望结论: 总费用为 {4}{W}{W}。可以横置最多 2 个白色生物支付 {W}{W}，最多 4 个任意生物支付 {4}。

- **题目**: 用召集支付费用时，对手能否 instant 响应？
  → 期望检索: CR 702.51a + CR 601.2h
  → 期望结论: 不能。召集是支付总费用的一部分，此时无优先权传递。
