# 复制效应裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 牌面包含 "copy" / "复制"
- 题目涉及复制咒语、永久物或异能
- 需要判断复制品的特征（P/T、颜色、异能、类别等）
- 需要判断复制品是否继承原咒语的模式、目标、X值等选择

## 检索路径（按优先级排序）

1. **CR 707.2 可复制特征值** → 确认复制品获得什么
   - **可复制特征值**：名称、法术力费用、颜色标志、类别、超类别、副类别、规则叙述、力量、防御力、忠诚
   - **会被应用的修改**：其他复制效应、牌面朝下状态、设定P/T的"于...进场"和"于...翻回正面时"异能
   - **不会被复制**：其他效应（类别改变、文字改变）、状态、指示物、贴纸

2. **CR 707.2a 颜色和异能** → 确认复制品的颜色和异能来源
   - 颜色来自法术力费用或颜色标志
   - 异能来自规则叙述
   - 不会从同一个异能中获得两组数值

3. **CR 707.2b 复制后独立性** → 确认原物件的改变不影响复制品
   - 一旦复制完成，改变原物件的可复制特征值不会导致复制品改变
   - 复制品是独立的新物件

4. **CR 707.10 复制咒语/异能** → 确认复制堆叠上的物件
   - 复制品放入堆叠，**没有被施放/起动**
   - **复制的决定**：模式、目标、X值、是否支付额外费用/替代性费用
   - **不复制的内容**：通常结算时才作出的选择
   - 复制品提及支付费用的物件时，使用原咒语支付费用时用到的物件
   - 复制异能时，复制品由创建它的牌手操控；复制品文字中的 `you/your` 按复制品操控者解释。若该异能有介入性 if（例如 `if you gained life this turn`），复制品结算时按复制品操控者检查该条件。
   - 复制目标异能后“you may choose new targets for the copy”只允许为复制品选择新的合法目标；目标合法性仍按复制品文字、操控者、X 值和区域限制判断。

5. **CR 608.2h 最后已知信息** → 原咒语离开堆叠后仍需复制
   - 如果复制效应需要一个已经离开公开区域的特定物件信息，使用该物件最后已知信息。
   - 延迟触发式异能复制“下一个被施放的咒语”时，该异能本身通常不以该咒语为目标；即使原咒语被反击离开堆叠，仍可用最后已知信息创建复制品。

6. **CR 707.4 战场上再复制** → 确认战场上永久物的再复制
   - 已复制永久物可以再复制不同永久物，**留在战场上**
   - **不触发**进入战场或离开战场异能
   - 已有的非复制效应**不会被改变**

## 常见陷阱

- **陷阱**: 复制品复制指示物
  → **正确理解**: CR 707.2。指示物**不是**可复制特征值，不会被复制。

- **陷阱**: 复制后原物件获得新异能，复制品也获得
  → **正确理解**: CR 707.2b。复制完成后两者独立，原物件的改变不影响复制品。

- **陷阱**: 复制品可以重新选择模式/目标/X值
  → **正确理解**: CR 707.10。复制品**继承**原咒语的所有决定，不能重新选择。但某些效应（如 Double Major）明确允许选择新目标。

- **陷阱**: 复制进战场的永久物时，进场触发会触发
  → **正确理解**: CR 707.4。如果永久物已在战场上再复制，不触发 ETB/LTB。但如果是**作为复制品直接放进战场**（如 Clone 进场时选择复制），则触发 ETB。

- **陷阱**: 具有文字改变效应（如 Humility）的生物被复制后，复制品也有改变后的文字
  → **正确理解**: CR 707.2。文字改变效应**不是**可复制特征值，不会被复制。复制品得到的是印刷文字。

- **陷阱**: 复制品的 mana value 等于被复制物件当前的费用
  → **正确理解**: 复制品得到的是**印刷的法术力费用**（受复制效应和进场替代性效应影响后的），不受费用改变效应影响。

- **陷阱**: 原咒语被反击后，已触发的复制效应找不到它，因而不创建复制品
  → **正确理解**: 若复制效应不以该咒语为目标，且需要该咒语的信息，会使用最后已知信息来创建复制品。

- **陷阱**: 复制一个触发式异能时，仍按原异能操控者检查“you”
  → **正确理解**: 异能复制品由创建它的牌手操控。复制品文字中的 “you” 指复制品操控者。

- **陷阱**: 复制带介入性 if 的触发式异能时，只看原异能操控者是否满足 if。
  → **正确理解**: 复制品结算时也要检查介入性 if；复制品中的 “you” 指复制品操控者。如果复制品操控者没有满足条件，复制品不会结算。

- **陷阱**: 改变原异能目标时，可以改到任意坟墓场中的牌。
  → **正确理解**: “change the target” 必须改成该原异能的合法目标。原异能的 `your graveyard` 仍指原异能操控者的坟墓场，X 值也仍按原异能确定；若没有其他合法目标，就不能改变。

## 测试验证

- **题目**: 一个带有+1/+1指示物的 2/2 生物被复制，复制品是几/几？
  → 期望检索: CR 707.2
  → 期望结论: 2/2。指示物不会被复制。

- **题目**: 复制一个选择了模式A、X=3、支付过 Kicker 的咒语，复制品的模式、X值、Kicker 状态是？
  → 期望检索: CR 707.10
  → 期望结论: 继承模式A、X=3、已支付 Kicker。不能重新选择。
