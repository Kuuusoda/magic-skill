# Combat Phase 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及战斗阶段的步骤顺序
- 题目涉及宣告攻击者的合法性（横置、敏捷、限制、要求）
- 题目涉及宣告阻挡者的合法性
- 题目涉及"被阻挡后牺牲阻挡者"的互动
- 题目涉及战斗伤害的分配规则
- 题目涉及被放进战场且"正在攻击"的生物

## 检索路径（按优先级排序）

1. **CR 506.1 战斗阶段五个步骤**
   - 战斗开始 → 宣告攻击者 → 宣告阻挡者 → 战斗伤害 → 战斗结束
   - 如果没有生物被宣告攻击，略过宣告阻挡者和战斗伤害步骤
   - 如果有先攻/连击生物，有两个战斗伤害步骤

2. **CR 508.1 宣告攻击者** → 回合动作，不使用堆叠
   - **508.1a**: 必须未横置、不能是战役、必须有敏捷或从回合开始持续操控
   - **508.1b**: 为每个攻击生物选择攻击对象（牌手/鹏洛客/战役）
   - **508.1c**: 检查限制（restrictions）— 违反任何限制 → 宣告非法
   - **508.1d**: 检查要求（requirements）— 必须满足尽可能多的要求
   - **508.1f**: 横置不是费用，攻击**导致**生物成为横置

3. **CR 506.4 移出战斗** → 生物何时不再是攻击/阻挡生物
   - 离开战场、改变操控者、跃离、重生、不再是生物、成为战役
   - **不会移出战斗**: 横置/重置已宣告的攻击者（CR 506.4b）
   - **不会移出战斗**: 阻止攻击/阻挡的效应在宣告后使用（CR 506.4a）

4. **CR 509 宣告阻挡者** → 回合动作，不使用堆叠
   - 阻挡生物必须未横置
   - 每个生物只能阻挡一个攻击生物（除非有特殊异能）
   - 宣告阻挡者后，攻击生物成为"被阻挡"或"未被阻挡"

5. **CR 510.1c 被阻挡生物的伤害分配** → 关键规则
   - 被阻挡生物对**当前阻挡它的生物**分配伤害
   - 如果阻挡者被牺牲/消灭 → 被阻挡生物**不分配战斗伤害**（除非有践踏）
   - 但该生物仍然是"被阻挡"状态
   - 多个阻挡者时，攻击方按任意顺序分配伤害

6. **CR 508.4 放进战场"正在攻击"** → 与"宣告攻击"的区别
   - 放进战场正在攻击的生物**不触发**"When this creature attacks"的异能
   - 不受宣告攻击者时的要求/限制影响

## 常见陷阱

- **陷阱**: 生物被阻挡后，响应牺牲阻挡者 → 伤害仍然分配给牌手
  → **正确理解**: 被阻挡生物不再被阻挡（阻挡者已死），但它仍然是"被阻挡生物"。除非有践踏，否则**不造成战斗伤害**。

- **陷阱**: 多个阻挡者时，攻击方可以跳过某个阻挡者来分配伤害
  → **正确理解**: CR 510.1c — 必须给每个阻挡者分配**至少等于致命伤害的量**，才能给下一个分配。不能跳过。死触来源只需1点即为致命。

- **陷阱**: 横置已宣告的攻击者可以阻止其造成战斗伤害
  → **正确理解**: CR 506.4b — 宣告后横置不阻止伤害，也不将其移出战斗。

- **陷阱**: "当此生物攻击时"的异能在生物被放进战场攻击时触发
  → **正确理解**: CR 508.3a — 只有被**宣告**为攻击者时才触发。放进战场攻击不算"宣告攻击"。

- **陷阱**: 先攻伤害步骤后，防御玩家可以施放瞬间
  → **正确理解**: 是的。先攻伤害步骤结束后，双方都有优先权，然后才进入普通伤害步骤。这是常见的响应窗口。

- **陷阱**: 攻击生物获得警戒后可以攻击而不横置
  → **正确理解**: 是的。警戒让攻击不导致横置，但宣告时生物仍需未横置。

## 测试验证

- **题目**: 3/3生物被1/1生物阻挡。防御玩家在宣告阻挡者后牺牲了1/1阻挡者。伤害步骤中3/3造成伤害吗？
  → 期望检索: CR 510.1c
  → 期望结论: 不造成伤害。3/3是被阻挡生物，当前没有阻挡它的生物，不分配伤害。但3/3仍处于被阻挡状态。

- **题目**: 一个具有"必须攻击"的生物，如果场上只有它一个生物，且一个效应为"不能只有单一生物攻击"，会怎样？
  → 期望检索: CR 508.1c, 508.1d
  → 期望结论: 不攻击。限制（不能只有单一生物攻击）优先于要求（必须攻击）。
