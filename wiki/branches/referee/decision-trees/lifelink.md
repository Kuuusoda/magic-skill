# Lifelink 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及系命生物造成伤害后获得多少生命
- 题目涉及多个系命实例的效果
- 题目涉及系命+死触+践踏的组合互动
- 题目涉及系命是触发式还是静止式（有版本变化）

## 检索路径（按优先级排序）

1. **CR 702.15a 系命是静止式异能** → 当前规则
   - 系命不是触发式异能，不使用堆叠
   - 造成伤害的同时获得生命——与其他伤害结果同时发生
   - 注意：史上曾有触发式版本的系命（如阿耶尼的血族），但关键字系命自 2010 年 M11 起即为静止式

2. **CR 702.15b 多个系命实例** → 不叠加
   - 一个永久物有多个系命实例 = 仍然获得等量生命
   - 系命实例数量不影响获得生命的量
   - 但如果一个效应说"相同来源造成的伤害同时获得生命"，这是独立的

3. **CR 120.3f 系命的生命获得** → 是伤害的结果
   - 伤害造成时，来源的操控者获得等量生命
   - 作为伤害处理步骤（CR 120.4）的结果部分发生

4. **CR 120.4a-c 系命在伤害处理中的位置** → 与伤害同时
   - a) 过量伤害修正 → b) 伤害造成 + 替代/防止 → c) 伤害结果（包括系命生命获得）
   - 系命在 c 步发生，与其他伤害结果（标记伤害、失去生命等）同时

## 常见陷阱

- **陷阱**: 系命是触发式异能，进入堆叠，可以响应
  → **正确理解**: 自 M11（2010）起，关键字系命是**静止式异能**。获得生命与伤害同时发生，不使用堆叠。不能"在获得生命前"做响应。

- **陷阱**: 系命获得的生命等于造成伤害的量，不是生物的防御力
  → **正确理解**: 3/3 系命对 1/1 造成 3 点伤害，操控者获得 3 点生命（不是 1 点）。

- **陷阱**: 系命+死触+践踏 5/5 被 4/4 阻挡，给阻挡者 1 点（死触致命伤害），给牌手 4 点。操控者获得 5 点生命
  → **正确理解**: 是的，获得 5 点生命。伤害总量为 1+4=5。

- **陷阱**: 有系命的来源对不灭生物造成伤害 → 不获得生命
  → **正确理解**: 伤害仍然**造成**了（只是不灭阻止了消灭）。系命仍然生效，操控者获得伤害量等量的生命。

- **陷阱**: 侵染+系命 → 获得生命 = 中毒指示物数量
  → **正确理解**: 侵染将伤害的**结果**从失去生命替代为获得中毒指示物。但伤害仍然**造成**了。系命获得的生命 = 造成的伤害量，不受侵染影响。例如 3/3 侵染系命 → 牌手得 3 个中毒指示物，操控者获得 3 点生命。

## 测试验证

- **题目**: 3/3 系命被 1/1 阻挡。操控者获得多少生命？
  → 期望检索: CR 120.3f
  → 期望结论: 3 点。伤害量为 3，不是 1。

- **题目**: 2/2 侵染系命对防御牌手造成战斗伤害。该牌手和攻击方各获得什么？
  → 期望检索: CR 120.3b, 120.3f
  → 期望结论: 防御牌手获得 2 个中毒指示物（不失去生命）。攻击方获得 2 点生命。
