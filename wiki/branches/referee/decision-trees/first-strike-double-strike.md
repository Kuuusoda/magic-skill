# First Strike / Double Strike 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及先攻/连击生物在战斗中的伤害时机
- 题目涉及先攻伤害步骤后阻挡者死亡对普通伤害步骤的影响
- 题目涉及多个先攻/连击/普通生物的伤害分配
- 题目涉及在一个战斗伤害步骤中刚获得先攻/连击的生物

## 检索路径（按优先级排序）

1. **CR 702.7b 先攻的定义** → 先攻在第一个战斗伤害步骤造成伤害
   - 有先攻的生物在**先攻战斗伤害步骤**中造成伤害
   - 没有先攻/连击的生物在此时**不造成伤害**（除非获得先攻/连击）
   - 两个战斗伤害步骤之间，双方获得优先权

2. **CR 702.4b 连击的定义** → 两个伤害步骤中都造成伤害
   - 在先攻伤害步骤中造成伤害（等于先攻的伤害）
   - 在普通伤害步骤中再造成一次伤害
   - 如果在先攻步骤后、普通步骤前被移除战场 → 不造成第二次伤害

3. **CR 510.5 两个战斗伤害步骤** → 何时有两个步骤
   - 如果**在先攻伤害步骤开始时**，有攻击或阻挡生物具有先攻或连击
   - 则存在两个战斗伤害步骤。否则只有一个
   - 即使生物在先攻步骤中死亡，也不影响第二个步骤的存在——先攻步骤开始时已经决定了

4. **CR 506.1 战斗阶段步骤** → 战斗开始 → 宣告攻击者 → 宣告阻挡者 → **先攻伤害** → **普通伤害** → 战斗结束

5. **CR 510.4 先攻伤害步骤造成伤害后** → 生物可能死亡
   - 先攻伤害分配并造成后，SBA 检查
   - 如果阻挡者在先攻伤害步骤中被消灭，它不再存在于普通伤害步骤中
   - 被先攻伤害消灭的生物**不造成战斗伤害**（除非有连击且在先攻步骤中也造成了伤害）

6. **CR 509.4g 在宣告后获得先攻** → 是否进入先攻伤害步骤
   - 如果宣告阻挡者后**没有任何生物**具有先攻/连击，但随后在优先权窗口中获得
   - 战斗伤害步骤开始时重新检查：有先攻/连击 → 使用先攻伤害步骤

## 常见陷阱

- **陷阱**: 先攻生物造成伤害后，防御玩家不能施放瞬间
  → **正确理解**: 先攻伤害步骤结束后，双方**都有**优先权。可以施放瞬间。这是重要的响应窗口。

- **陷阱**: 先攻伤害步骤中被阻挡的生物，其阻挡者在先攻步骤死亡 → 攻击生物在普通步骤中"不被阻挡"了，可以攻击牌手
  → **正确理解**: 攻击生物已经**被阻挡**了，该状态不会改变（CR 506.4a）。它在普通伤害步骤中仍是"被阻挡生物"，不造成战斗伤害（除非有践踏）。

- **陷阱**: 连击生物先攻步骤打了 3 点，普通步骤再打 3 点，总共得打 6 点伤害吸收
  → **正确理解**: 连击确实在两个步骤中各造成伤害，两次伤害都单独计算。如果先攻步骤的伤害标记已经等于或超过防御力（致命伤害），生物在普通伤害步骤前就被 SBA 消灭。

- **陷阱**: 在第一时间获得先攻（如通过战斗诡计），就可以在先攻伤害步骤造成伤害
  → **正确理解**: 是的，前提是在先攻伤害步骤**开始前**获得。但如果在先攻伤害步骤结束后才获得先攻，该生物已在普通伤害步骤，先攻无效（CR 510.5）。

## 测试验证

- **题目**: 3/3 连击被 2/2 先攻阻挡。结果如何？
  → 期望检索: CR 702.4b, 702.7b
  → 期望结论: 两者都在先攻伤害步骤造成伤害。3/3 打 3 给 2/2，2/2 打 2 给 3/3。3/3 标记 2 点伤害，2/2 标记 3 点致命伤害 → SBA 消灭 2/2。普通伤害步骤：3/3 没有阻挡者（已死），但仍是"被阻挡"状态，不造成伤害（除非有践踏）。

- **题目**: 3/3 普通生物在宣告阻挡者后获得先攻（如通过闪现武具）。它能在先攻步骤打伤害吗？
  → 期望检索: CR 510.5
  → 期望结论: 能。如果它在先攻伤害步骤开始前获得先攻，就可以。因为步骤开始时重新检查。
