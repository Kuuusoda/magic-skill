# Lands 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及使用地牌的时机和数量限制
- 题目涉及地的类别改变（如腥红之月）
- 题目涉及地生物和地永久物的区别
- 题目涉及"额外使用地牌"效应的叠加
- 题目涉及地是否可以被指定为目标/消灭

## 检索路径（按优先级排序）

1. **CR 305.1 使用地牌** → 特殊动作，不使用堆叠
   - 使用地牌**不是施放咒语**
   - 何时可以使用：只有在你的行动阶段、堆叠为空、有优先权、且本回合还有可用次数时
   - CR 116.2a：使用地牌是特殊动作，不使用堆叠，不能被响应

2. **CR 305.2 每回合一次** → 默认限制
   - 默认每个牌手的每个回合只能使用 1 张地牌
   - "额外使用地牌"的效应增加此限制（如 Azusa, Lost but Seeking）
   - 多个额外使用地牌的效应**叠加**

3. **CR 305.3 地为何不给优先权** → 使用地后优先权不变
   - 使用地牌后，主动牌手仍然拥有优先权
   - 因为使用地牌不使用堆叠，不会导致优先权转移

4. **CR 305.4 地没有颜色** → 除非有别的效应
   - 地牌默认为无色（CR 202.2b）
   - 但地的颜色标识（color identity）由牌面上的有色法术力符号决定（对指挥官等格式重要）

5. **CR 305.6 地的基本类别** → 平原、海岛、沼泽、山脉、树林
   - 有基本类别的地具有对应的法术力异能："{T}: 加 [对应颜色]"
   - 地获得基本类别时获得该异能（如腥红之月将非基本地变成山脉）

6. **CR 305.7 地生物** → 地同时是生物
   - 地生物受召唤失调影响（不能攻击或使用 {T} 异能，除非有敏捷）
   - 地生物可以被"消灭目标生物"和"消灭目标地"分别影响

7. **CR 305.8 地产生法术力** → 大部分地依赖法术力异能
   - 横置产生法术力是法术力异能，不使用堆叠

## 常见陷阱

- **陷阱**: 使用地牌可以被响应
  → **正确理解**: 使用地牌是特殊动作，不使用堆叠，不能被响应。对手不能"响应你下地"来做什么。

- **陷阱**: 腥红之月把非基本地**变成**山脉后，它仍然保留其他类别
  → **正确理解**: 腥红之月将非基本地的**地类别**变成山脉（层 4），移除其他异能（层 6）。结果：地失去所有原本的异能，只保留"{T}: 加 {R}"。

- **陷阱**: 一个永久物既是地又是生物（如通过变成生物的效应），不能攻击
  → **正确理解**: 它是生物，所以可以攻击。但它也是地，所以如果是从这回合开始操控的，就有召唤失调（除非有敏捷）。

- **陷阱**: 地生物被"消灭所有地"消灭，是消灭不是死亡？
  → **正确理解**: 它是生物也是地，被消灭后进入坟墓场，触发"当生物死去时"的异能。地不重要——它仍然是生物在死亡。

## 测试验证

- **题目**: 腥红之月在场，使用聚污三角洲（Polluted Delta）。可以起动聚污三角洲的异能吗？
  → 期望检索: CR 305.6, 层系统 613.1
  → 期望结论: 不可以。聚污三角洲变成山脉（层 4），失去所有其他异能（层 6），只保留{T}: 加{R}。

- **题目**: 回合中使用了 2 张地（有 Azusa），使用第一张地后可以响应吗？
  → 期望检索: CR 305.1, 116.2a
  → 期望结论: 不能响应。使用地牌是特殊动作，不使用堆叠。
