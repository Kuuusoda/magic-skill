# Counters 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及指示物的放置、移除或加倍
- 题目涉及 +1/+1 和 -1/-1 指示物的抵消
- 题目涉及增殖（proliferate）对指示物的影响
- 题目涉及生物获得 -1/-1 指示物后是否会死亡
- 题目涉及具有指示物的永久物被复制或改变区域

## 检索路径（按优先级排序）

1. **CR 122.1 指示物的定义** → 指示物是放置在物件上的标记
   - 指示物可以改变永久物的特征
   - 指示物本身不是永久物，不是衍生物

2. **CR 122.3 +1/+1 和 -1/-1 指示物的抵消** → 关键规则
   - 同一永久物上同时有 +1/+1 和 -1/-1 指示物
   - 在 SBA 检查时（704.5q）成对抵消：移除 N 对，N 为较少者的数量
   - 这是**唯一**互相抵消的指示物类型
   - +1/+1 和 -1/-1 以外的同名但相反的指示物**不会**自动抵消

3. **CR 122.5 指示物的加倍效应** → 何时加倍
   - "加倍指示物" = 给已有指示物的永久物再放置等量的该种指示物
   - 只对"将被放置的指示物"生效，不对已有的指示物加倍
   - 多个加倍效应——每个操控者按顺序选择适用哪个

4. **CR 122.6 指示物的替代效应** → 放置指示物的替代
   - "改为放两倍"的效应明确替代放置事件
   - 与加倍效应（122.5）有区别——阅读牌面仔细判断

5. **CR 122.8 永久物离场** → 指示物离开战场时消失
   - 指示物只存在于战场上。生物死亡进入坟墓场后，指示物消失
   - 例外：骷髅妖（MTG 未来设定）可以在非战场区域保留指示物

6. **CR 704.5q SBA 抵消** → +1/+1 和 -1/-1 抵消是 SBA
   - 不使用堆叠
   - 抵消后如果防御力≤0（704.5f）或标记伤害≥防御力（704.5g），生物也会死亡

## 常见陷阱

- **陷阱**: 一个 2/2 生物上有 2 个 +1/+1 指示物，得到一个 -4/-4 效应后防御力为 0
  → **正确理解**: 首先，-4/-4 到回合结束是持续性效应（层 7），不是 -1/-1 指示物。生物是 2+2=4 再 -4=0，防御力为 0 直接置入坟墓场（704.5f）。没有指示物抵消发生。

- **陷阱**: charge counter 和 -1/-1 counter 会互相抵消
  → **正确理解**: CR 122.3 — 只有 +1/+1 和 -1/-1 指示物会互相抵消。其他类型的指示物不会。

- **陷阱**: 增殖一次只能给一种永久物加指示物
  → **正确理解**: 增殖一次可以给**每个**操控的永久物和/或牌手选择一个已有的指示物种类，各加一个指示物。

- **陷阱**: 0/0 生物进战场带 3 个 +1/+1 指示物，触发"当生物进战场时"异能之前就死了
  → **正确理解**: 指示物与生物同时进战场（CR 614.12）。生物进战场时是 3/3，不会触发 SBA。

## 测试验证

- **题目**: 一个生物上同时有 3 个 +1/+1 指示物和 2 个 -1/-1 指示物。SBA 检查后还剩多少？
  → 期望检索: CR 704.5q, 122.3
  → 期望结论: 2 对抵消，剩余 1 个 +1/+1 指示物。

- **题目**: 操控 2 个加倍指示物的效应。一个效应要放置 1 个指示物，结果放几个？
  → 期望检索: CR 122.5
  → 期望结论: 每个操控者按 APNAP 顺序选择：第一个加倍由一方选放置 2 个，第二个加倍由另一方选改为放置 4 个。
