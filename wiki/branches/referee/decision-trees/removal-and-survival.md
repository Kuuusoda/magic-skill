# Removal & Survival 裁判决策树

涵盖永久物离开/留在战场的核心机制：死亡、消灭、牺牲、不灭、重生。

## 识别条件

以下任一情况触发此决策树：
- 题目涉及"死亡"、"消灭"、"牺牲"三者的规则区别
- 题目涉及不灭/重生是否能防止某效应
- 题目涉及防御力≤0、传奇规则、放逐是否算"消灭"
- 题目涉及重生后生物的状态（指示物、灵气、横置）

---

## 一、死亡 / 消灭 / 牺牲

### 检索路径

1. **CR 700.4 "死亡"（Dies）** → 从战场进入坟墓场
   - "Dies" = 从战场置入坟墓场
   - 任何原因：被消灭、牺牲、防御力≤0、传奇规则 → 都是"死亡"
   - 放逐**不是**死亡

2. **CR 701.7 "消灭"（Destroy）** → 将永久物从战场置入坟墓场
   - 只有字面含 "destroy" 的效应才是消灭
   - 不灭阻止消灭（702.12b），重生可替代消灭（701.15a）

3. **CR 701.17 "牺牲"（Sacrifice）** → 牌手选择自己的永久物置入坟墓场
   - 不是消灭 → 不灭不能阻止、重生不能替代
   - "目标牌手牺牲一个生物"——目标是牌手，不是生物

4. **CR 704.5f 防御力≤0** → "置入坟墓场"
   - 不是消灭 → 不灭不能防止、重生不能替代
   - 生物**死亡了**（进入坟墓场）

### 关键对照表

| 事件 | 是消灭？ | 不灭防止？ | 重生替代？ | 算死亡？ |
|------|----------|------------|------------|----------|
| 致命伤害 SBA (704.5g) | 是 | 是 | 是 | 是 |
| 死触 SBA (704.5h) | 是 | 是 | 是 | 是 |
| 防御力≤0 (704.5f) | 否 | 否 | 否 | 是 |
| 牺牲 (701.17) | 否 | 否 | 否 | 是 |
| 传奇规则 (704.5j) | 否 | 否 | 否 | 是 |
| 放逐 | 否 | 否 | 否 | 否 |
| 反击（咒语） | 否 | — | — | — |

## 二、不灭 Indestructible (CR 702.12)

### 检索路径

1. **CR 702.12b** → 永久物不灭 = 不被消灭
   - 致命伤害标记不导致被消灭（免疫 704.5g）
   - 任何"消灭"效应不将其消灭
   - 死触伤害不消灭不灭生物（死触通过 704.5h 消灭）

2. **CR 702.12c** → 伤害仍然标记，清除步骤移除

3. **不灭不保护的死亡方式**：
   - 防御力≤0（-X/-X 效应、-1/-1 指示物）
   - 牺牲
   - 传奇规则
   - 放逐

### 常见陷阱

- **不灭=无敌？** 不对。防御力≤0 仍然会死，牺牲和放逐仍然有效。
- **不灭+死触？** 死触伤害不杀死不灭生物。
- **不灭+侵染？** 侵染将伤害替换为 -1/-1 指示物，可能将防御力减至 ≤0 → 死亡。不灭不管。

## 三、重生 Regeneration (CR 701.15)

### 检索路径

1. **CR 701.15a** → 重生是替代式效应
   - "重生"一个永久物 → 创建**重生盾**
   - 效果：下一次该永久物**将要被消灭**时，改为：横置它、移除所有标记伤害、移出战斗

2. **CR 701.15b** → 不进入坟墓场
   - 从未离开战场 → 不触发"死亡"异能
   - 指示物保留、灵气/武具保留

3. **CR 701.15c** → 以下不能被重生替代
   - 防御力≤0、牺牲、传奇规则/普世规则

4. **CR 701.15e** → 重生移出战斗
   - 已被阻挡的生物被重生移除战斗 → 仍是"被阻挡"状态
   - 不造成也不受战斗伤害

### 重生 vs 不灭

| | 重生 | 不灭 |
|---|---|---|
| 对"消灭" | 替代（横置+脱战+移除伤害） | 忽略（完全不消灭） |
| 有使用次数？ | 每次盾消耗一个 | 持续有效 |
| 横置生物？ | 是 | 否 |
| 对多次消灭 | 需要多个盾 | 全部忽略 |
| 防御力≤0 | 不能替代 | 不能防止 |

### 常见陷阱

- **重生 = 从坟场复活？** 不对。重生**替代**消灭，永久物从未进入坟墓场。
- **重生后指示物丢失？** 不对。没有区域改变，指示物保留。
- **一回合内需要几个重生盾？** 每个"消灭"事件消耗一个盾。多个消灭事件需要多个盾。

## 测试验证

- **题目**: 4/4 不灭生物，受到 4 点伤害，再得 -4/-4 直到回合结束。会死吗？
  → 期望结论: 会。防御力变为 0，由 704.5f 置入坟墓场（不是消灭）。

- **题目**: 一个生物有重生盾，被"消灭目标生物"两次。会死吗？
  → 期望结论: 会。第一个消灭被盾替代，第二个消灭没盾保护 → 死亡。

- **题目**: 不灭生物能被牺牲吗？
  → 期望结论: 能。牺牲不是消灭，不灭不保护。
