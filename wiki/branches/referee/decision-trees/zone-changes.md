# Zone Changes 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及永久物改变区域后的特征
- 题目涉及"离开战场时"异能的触发
- 题目涉及生物死亡 → 坟墓场后特征的变化
- 题目涉及"当...从任何地方置入坟墓场时"的异能
- 题目涉及被放逐后"返回战场"时的特征
- 题目涉及生物从战场进入其他区域时是否保留指示物/灵气/武具

## 检索路径（按优先级排序）

1. **CR 400.7 改变区域的对象成为新对象** → 核心规则
   - 物件从一个区域移动到另一个区域 → 成为**新对象**
   - 新对象不记得之前区域中的状态、指示物、灵气、武具等
   - 所有记忆与旧物件的关系全部切断
   - 例外：以下效应**可以**追踪：回到战场的物件（如云移——放逐后立即返回）、变为牌面朝下的物件

2. **CR 400.7e 放逐后返回战场** → 例外情况
   - 某些效应将物件放逐后"返回"战场 → 返回后**仍是同一物件**
   - 前提：在放逐区中能被追踪（未被洗入牌库等）
   - 例子：云移（blink）效应——放逐目标生物，然后将其返回战场。回来的是同一个物件

3. **CR 400.7a-h 其他区域变更的例外** → 9 种特殊处理
   - a) 改变区域的物件身上的效应追踪（如"直到回合结束，目标生物得 +3/+3"——区域改变后效应不再生效）
   - d) 从堆叠结算后进入战场的咒语，其"不能再被反击"的效应失效
   - g) 区域变更时 +1/+1 和 -1/-1 指示物的移除等

4. **CR 603.6c "离开战场时"触发条件** → 基于离开前的状态
   - "当[永久物]离开战场时"——检查的是永久物**离开战场前**最后存在于战场上的状态
   - 但异能的来源是该物件在**离开战场所进入的区域**中的新对象

5. **CR 603.10 触发式异能回头看区域变更** → "当...从任何地方置入坟墓场时"
   - 如"当一张牌从任何地方置入你的坟墓场时"——检查该物件在**进入坟墓场前**所在区域的特征
   - 例如：生物从战场死亡 → 检查的是战场上的特征（可能被层效应修改过）

## 常见陷阱

- **陷阱**: 云移回来的生物保留了之前的灵气
  → **正确理解**: 云移后生物成为新对象（CR 400.7），灵气留在战场上（未贴附→ SBA 704.5m 将其置入坟墓场）。

- **陷阱**: 生物死亡回到坟墓场后，坟场中的牌"记得"它在战场上的指示物
  → **正确理解**: 区域改变后是新对象。指示物不会跟随进入坟墓场。

- **陷阱**: "离开战场时"的异能在生物被放逐时触发
  → **正确理解**: 是的。放逐是从战场进入放逐区的区域改变，触发"离开战场时"的异能。

- **陷阱**: 被放逐后回到战场的生物，其"当此生物进战场时"异能不触发
  → **正确理解**: 会触发。即使返回的是同一物件，它仍然是**进入战场**，触发了 ETB 异能。

## 测试验证

- **题目**: 生物被放逐，然后立即被另一个效应从放逐区移回手牌。原来的灵气在哪里？
  → 期望检索: CR 400.7, 704.5m
  → 期望结论: 灵气留在战场，在 SBA 检查时因不合法贴附而置入坟墓场。生物在手牌中是新对象。

- **题目**: 生物被云移（放逐并返回战场）。它进战场时触发 ETB 吗？
  → 期望检索: CR 400.7e, 603.6
  → 期望结论: 触发。即使返回的是同一个物件，它仍然进入了战场。
