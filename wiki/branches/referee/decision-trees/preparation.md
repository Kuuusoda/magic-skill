# Preparation / Prepared 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 牌面或题目包含 `prepare`、`prepared`、`unprepared`
- 永久物具有 `//Prep//` 副特征或备法咒语
- 题目涉及从放逐区施放备法咒语复制品
- 题目涉及备法复制品离开放逐区、被反击、或复制效应结束

## 检索路径

1. **CR 722.2b 备法副特征的可复制性**
   - 备法咒语副特征的存在和值是物件可复制特征值的一部分。
   - 复制一个具有备法咒语的永久物时，复制品也具有对应备法咒语副特征。

2. **CR 722.3a 获得 prepared 称号**
   - 某些咒语或异能会使具有备法咒语的永久物成为 prepared，或注明进场时 prepared。
   - `prepared` 是 designation，用作规则和效应辨识的标记。
   - 永久物不能在没有备法咒语时获得 prepared；已经 prepared 的永久物不能再次获得 prepared。

3. **CR 722.3b 变为 unprepared**
   - 只有规则或效应使永久物成为 unprepared 时，才移除 prepared 称号。
   - 复制效应结束、失去某些可复制文字、或另一个复制品消失，本身不等于变为 unprepared。

4. **CR 722.3c 放逐区备法复制品**
   - 当具有备法咒语的永久物获得 prepared 称号或跃回且 prepared 时，其操控者在放逐区创建一个仅具有该备法咒语特征的复制品。
   - 如果永久物“enters prepared”，获得 prepared 称号和创建备法复制品发生在该永久物进场时；这不是进入堆叠的触发式异能。
   - 只要对应 prepared 永久物仍在战场且仍具有 prepared 称号，该复制品留在放逐区；这是 CR 704.5e 的例外。
   - 该复制品留在放逐区期间，其操控者可以施放它。
   - 该咒语成为被施放时，对应永久物失去 prepared 称号（见 CR 601.2i）。
   - 若该永久物之后再次由其他咒语或异能成为 prepared，会创建一个新的放逐区备法复制品；这是新的对象，和此前已经被施放、在堆叠上的复制品不同。

5. **CR 704.5e / 707.10a 复制品在非堆叠区域消失**
   - 咒语复制品处于非堆叠区域时会消失。
   - 牌的复制品处于非堆叠或战场区域时会消失。
   - CR 722.3c 的例外只保护仍在放逐区、仍由 prepared 永久物维持的备法复制品。

## 常见陷阱

- **陷阱**: `This creature enters prepared` 是触发式异能。
  → **正确理解**: 这是进场时获得 designation 的规则处理，不是进入堆叠的触发式异能。

- **陷阱**: 永久物进场 prepared 后，牌手可在同时进场的其他 ETB 触发进入堆叠前施放备法复制品。
  → **正确理解**: 咒语或异能结算期间没有牌手获得优先权。结算完成后，所有等待进入堆叠的触发式异能先按 APNAP 放入堆叠，然后主动牌手才获得优先权。因此如果同时进场的永久物触发了“使该生物 unprepared”的异能，牌手不能抢在该触发入堆叠前施放法术时机的备法复制品；若堆叠非空且复制品是法术，也不能在该触发结算前施放。

- **陷阱**: 备法复制品被施放后仍受 722.3c 保护。
  → **正确理解**: 被施放时它离开放逐区进入堆叠，成为新物件。之后若被反击并放逐，不再是 722.3c 所保护的放逐区备法复制品，会按 704.5e / 707.10a 消失。

- **陷阱**: 把“已经施放、在堆叠上的备法复制品”和“后来重新 prepared 创建的放逐区备法复制品”当成同一个对象。
  → **正确理解**: 施放备法复制品会让对应永久物 unprepared，并让该复制品作为咒语进入堆叠。若该永久物之后再次成为 prepared，会在放逐区创建新的备法复制品。后续反击或放逐堆叠上的旧复制品，不会自动移除这个新获得的 prepared 称号，也不会让新放逐区复制品消失，除非永久物离开战场或变为 unprepared。

- **陷阱**: 只因为一个备法复制品被施放，就认为之后所有放逐区备法复制品都会消失。
  → **正确理解**: 必须按时间线逐个对象判断。只有对应永久物当前不在战场或当前没有 prepared 称号时，722.3c 维持的放逐区复制品才失去例外保护。

- **陷阱**: 复制效应结束会自动使永久物 unprepared。
  → **正确理解**: prepared 是 designation。722.3a 限制“获得”称号的时点，722.3b 说明只有规则或效应使其 unprepared 时才移除称号。

- **陷阱**: 已创建的备法复制品会随着永久物后来可复制值改变而改变。
  → **正确理解**: 备法复制品创建时成为独立物件，其特征不会随之后复制效应结束或源永久物文字改变而改变。
