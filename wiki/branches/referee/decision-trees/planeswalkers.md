# Planeswalkers 裁判决策树

## 识别条件

以下任一情况触发此决策树：
- 题目涉及鹏洛客受到伤害后移除忠诚指示物
- 题目涉及鹏洛客的忠诚异能是否使用堆叠
- 题目涉及攻击鹏洛客时的伤害分配
- 题目涉及鹏洛客的传奇规则（多个同名鹏洛客）
- 题目涉及鹏洛客成为生物后的规则

## 检索路径（按优先级排序）

1. **CR 306.2 鹏洛客的伤害** → 非战斗伤害
   - 非战斗伤害对牌手造成时 → 该伤害来源的操控者可以将该伤害**转移**给由该牌手操控的一个鹏洛客
   - "任意一个目标"（any target）可以直接选择鹏洛客为目标
   - "目标牌手"的非战斗伤害不能直接指向鹏洛客，但可以在结算时转移

2. **CR 306.5 忠诚异能** → 每回合只能起动一次
   - 忠诚异能是**鹏洛客的异能**，不是牌手的能力
   - 每个鹏洛客在你操控下的每回合只能使用**一个**忠诚异能
   - 忠诚异能的费用是增加/减少忠诚指示物

3. **CR 306.5c 忠诚异能不是法术力异能** → 使用堆叠
   - 即使忠诚异能产生法术力，也不是法术力异能（CR 606.3）
   - 使用堆叠，可以被响应（如扼）

4. **CR 306.6 鹏洛客的战斗伤害** → 通过攻击分配
   - 宣告攻击者时可以选择鹏洛客为攻击对象
   - 鹏洛客的战斗伤害 → 移除等量的忠诚指示物（CR 120.3c）
   - 生物可以同时攻击牌手和鹏洛客（各自的攻击者分别选择）

5. **CR 306.7 鹏洛客的传奇规则** → 鹏洛客类别视为名称
   - 如果同一个牌手操控两个或更多同名鹏洛客 → 传奇规则适用（704.5j）
   - 注意：鹏洛客**类别**就是它的名称（如"Jace"），不是牌名（"Jace, the Mind Sculptor"）
   - 所以一个牌手不能同时操控两个类别为"Jace"的鹏洛客（即使牌名不同）

6. **CR 306.8 鹏洛客受到伤害** → 移除忠诚指示物
   - 无论伤害来源是什么，鹏洛客受到伤害 = 移除等量忠诚指示物
   - 忠诚指示物为 0 → SBA 704.5i 将其置入坟墓场
   - 死触对鹏洛客没有特殊效果（CR 704.5h 只针对生物）

## 常见陷阱

- **陷阱**: 鹏洛客是牌手
  → **正确理解**: 鹏洛客是**永久物**，不是牌手。能被咒语/异能指定为目标。牌手不是永久物，不能被"消灭目标永久物"指定。

- **陷阱**: 闪电击目标牌手 → 不能打鹏洛客
  → **正确理解**: 闪电击是"any target"，可以直接选择鹏洛客为目标。

- **陷阱**: "不能指定鹏洛客为目标"的咒语 → 可以指定牌手然后转移
  → **正确理解**: 转移规则（CR 306.2）只适用于**非战斗伤害**。但大多数新牌直接使用 any target 或指定鹏洛客。

- **陷阱**: 可以同时操控多个不同名的"Jace"鹏洛客（如 Jace, the Mind Sculptor 和 Jace Beleren）
  → **正确理解**: 不可以。鹏洛客类别"Jace"就是传奇规则的判定依据。两者都是传奇鹏洛客 — Jace，触发传奇规则。

- **陷阱**: 鹏洛客被攻击时，防御牌手的生物可以阻挡
  → **正确理解**: 是的。攻击生物宣告攻击鹏洛客后，防御牌手可以用自己的生物阻挡。鹏洛客本身不阻挡。

## 测试验证

- **题目**: 防御牌手操控一个 3 忠诚的鹏洛客。对手宣告 2/2 和 3/3 两个生物都攻击该鹏洛客。能阻挡吗？
  → 期望检索: CR 508.1b, 509.1a
  → 期望结论: 防御牌手可以宣告阻挡者来阻挡这两个攻击生物。如果全部不阻挡，鹏洛客失去 5 个忠诚指示物 → 忠诚为 0 → SBA 将其置入坟墓场。

- **题目**: 一个鹏洛客类别是"Chandra"的鹏洛客在场。牌手施放另一个类别为"Chandra"的鹏洛客。会发生什么？
  → 期望检索: CR 704.5j, 306.7
  → 期望结论: 新 Chandra 进战场后，SBA 检查发现两个同名传奇鹏洛客。操控者选择一个保留，另一个置入坟墓场。
