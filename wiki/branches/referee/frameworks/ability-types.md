# 异能类型识别框架

## 框架定位

当题目涉及**识别异能类型**（触发式、起动式、静止式、魔法力、特殊）时，使用本框架进行分类。

## 判定步骤

### 步骤1：检查异能的文字格式

| 格式特征 | 异能类型 | CR 引用 |
|---------|---------|---------|
| "[费用]：[效应]" | **起动式异能** | 602.1 |
| "When/Whenever/At [事件]，[效应]" | **触发式异能** | 603.1 |
| 没有冒号，持续生效的描述 | **静止式异能** | 604.1 |
| 产生魔法力的异能 | **魔法力异能** | 605.1 |
| 特殊关键词（如勘察、召集等） | **特殊异能** | 各关键词定义 |

### 步骤2：区分起动式 vs 触发式

关键区分点：
- **起动式**: 牌手主动选择**何时**支付费用来起动（有费用和冒号）
- **触发式**: 游戏自动在**特定事件发生时**触发（无费用，有 When/Whenever/At）

常见混淆：
- "当...时" 不是起动式，是触发式
- 具有 Flash 的生物其 Flash 是**静止式异能**，不是起动式

### 步骤3：识别触发式异能的子类型

| 子类型 | 识别特征 | 处理规则 |
|--------|---------|---------|
| 普通触发 | "When/Whenever [事件]" | 标准触发规则 |
| 介入性 if | "...if [条件]，[效应]" | 603.4：触发时和结算时各检查一次 |
| 延迟触发 | "When/At [未来时间]，[效应]" | 603.7：在事件发生后创建 |
| 自身触发 | "When you do，[效应]" | 603.12：遵循延迟触发规则 |
| Modal 触发 | "Choose one —" 前缀 | 700.2b：进入堆叠时选择模式 |

### 步骤4：识别静止式异能的子类型

| 子类型 | 识别特征 | 例子 |
|--------|---------|------|
| 特征定义异能 | 定义物件的内在特征 | Changeling、力量/防御力设定 |
| 复制效应 | "是...的复制品" | Clone |
| 替代性效应 | "改为" / "略过" / "须...进场" | 614 |
| 防止性效应 | "防止" | 615 |
| 持续性规则改变 | 改变游戏规则 | "生物不能进行攻击" |

### 步骤5：判断是否为魔法力异能

**魔法力异能的条件**（必须同时满足）：
1. 是起动式异能，且**没有目标**；或
2. 是触发式异能，且**由魔法力费用起动**且**没有目标**
3. **效应**是加魔法力到魔法力池、或支付 {X}

**关键特征**: 魔法力异能**不使用堆叠**，无法被响应。

## 关键规则引用

- CR 602.1: 起动式异能
- CR 603.1: 触发式异能
- CR 604.1: 静止式异能
- CR 605.1: 魔法力异能
- CR 603.4: 介入性 if
- CR 603.7: 延迟触发
- CR 603.12: 自身触发

## 常见判例

| 案例 | 文字格式 | 结论 |
|------|---------|------|
| "{T}：加 {G}" | [费用]：[效应] | 起动式魔法力异能，不使用堆叠 |
| "When this enters，draw a card" | When [事件]，[效应] | 触发式异能 |
| "You may cast... as though..." | 无冒号，持续生效 | 静止式异能（给予许可） |
| "Prevent all damage..." | 无冒号，"防止" | 静止式中的防止性效应 |
| "If a source would deal damage，it deals double" | 无冒号，"改为" | 静止式中的替代性效应 |
| "Cascade" | 关键词 | 触发式异能（702.85a） |
| "Convoke" | 关键词 | 静止式异能（702.51a） |
