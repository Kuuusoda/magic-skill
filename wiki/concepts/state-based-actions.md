# 状态动作（State-Based Actions，SBA）

## 定义

状态动作是游戏规则自动执行的检查机制，用于维护游戏状态的一致性。它们**不使用堆叠**，**不能被响应**，在特定时机（某位牌手将要获得优先权时、以及作为清除步骤的一部分）自动执行（CR 704）。

## 状态动作的触发时机

状态动作在以下时刻检查并执行：
1. **在任何牌手将要获得优先权之前**
2. **在清除步骤中**
3. **在战斗伤害步骤中，伤害分配和造成之后**

> 关键特性：状态动作不会在咒语或异能结算的过程中间执行。它们只会在上述特定时机批量执行。

## 主要状态动作列表（CR 704.5）

### 1. 生物死亡（ toughness ≤ 0 ）
若一个生物的防御力为 0 或更小，它被置入其拥有者的坟墓场（CR 704.5f）。

### 2. 生物受到致命伤害
若一个生物受到的伤害总量大于或等于其防御力，且该伤害本回合未被防止，它被置入其拥有者的坟墓场（CR 704.5g）。

> **注意**：具有不灭异能的生物不受此状态动作影响。

### 3. 鹏洛客忠诚度为 0
若一个鹏洛客的忠诚指示物数量为 0，它被置入其拥有者的坟墓场（CR 704.5i）。

### 4. 牌手生命为 0
若一个牌手的生命总值为 0 或更少，该牌手输掉游戏（CR 704.5a）。

### 5. 牌手需要抓牌但牌库为空
若一个牌手试图从空的牌库中抓牌，该牌手输掉游戏（CR 704.5b）。

> **注意**：牌库为空本身不会导致输牌，只有在"需要抓牌但无法抓"时才会输。

### 6. 传奇规则
若一个牌手操控两个或更多同名的传奇永久物，该牌手选择其中一个保留，其余的置入其拥有者的坟墓场（CR 704.5j）。

### 7. 战场限制
若一个牌手操控的永久物数量超过某个规则或效应允许的最大值，该牌手选择超出的永久物置入坟墓场（CR 704.5k，如某些休闲玩法中的限制）。

### 8. 灵气/武具失去目标
若一个灵气结附的物件不再存在于战场上、或不再合法、或灵气不再受其操控者操控，该灵气被置入其拥有者的坟墓场（CR 704.5m）。

> 类似地，若一个武具所佩带的生物不再存在于战场上，该武具留在战场上但不再佩带在任何生物上（"unattached"）。

### 9. 衍生物离开战场
若一个衍生物在任何区域中（非战场），它消失（ceases to exist）（CR 704.5d）。

### 10. 徽记离开统帅区
若一个徽记在任何区域中（非统帅区），它消失（CR 704.5e）。

## 状态动作检查的迭代性

状态动作不是只检查一次。在执行完一批状态动作后，游戏会**再次检查**是否有新的状态动作需要执行。这个过程重复直到没有任何状态动作需要执行，然后牌手才获得优先权。

这意味着：
- 多个状态动作可以同时发生
- 一个状态动作可能导致另一个状态动作（例如：生物死亡后，灵气也随之进入坟墓场）
- 所有结果同时产生，然后再次检查

## 状态动作与触发式异能的顺序

当状态动作和触发式异能同时需要处理时：
1. 首先执行所有状态动作
2. 然后检查由这些状态动作导致的触发式异能（例如「当此生物死去时…」）
3. 这些异能进入堆叠
4. 然后主动牌手获得优先权

## 常见误区

### "状态动作可以被响应"
**错误**。状态动作不使用堆叠，不能被咒语或异能响应。但你可以在状态动作检查**之前**的时机（即上一次获得优先权时）采取行动。

### "伤害会立刻杀死生物"
**错误**。伤害本身不会立刻杀死生物。只有在状态动作检查的下一个时机，若该生物的防御力 ≤ 受到的伤害总量，它才会死亡。

### "鹏洛客忠诚度降到 0 会立刻进坟"
**错误**。鹏洛客忠诚度降到 0 后，会在下一个状态动作检查时才会被置入坟墓场。在此期间，若有异能可以影响它，它仍然存在于战场上。
