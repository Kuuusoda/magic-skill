# 争斗（Fight）

## 定义

争斗（Fight）是万智牌中的关键字动作，指两个生物各对另一个生物造成等同于其力量的伤害。争斗**不是战斗**，不使用正常的战斗阶段规则，而是作为咒语或异能的效应直接发生（CR 701.12）。

## 核心规则

### 争斗流程
1. 两个指定的生物**各对另一个**造成等同于其**当前力量**的伤害
2. 伤害同时造成
3. 造成的伤害视为**由该生物本身**造成的（会触发如死触、系命等相关异能）
4. 争斗**不是战斗伤害**，因此不会被先攻/连击影响

### 关键限制
- 争斗的目标必须是**战场上的生物**
- 争斗的目标不能是同一个生物（必须两个不同的生物）
- 若其中一个目标在争斗结算前已离开战场，则争斗仍然发生，另一个生物不会对任何东西造成伤害
- 争斗中的生物不需要是未横置的，也不需要由主动牌手操控

### 与战斗的区别

| 特性 | 争斗 | 正常战斗 |
|------|------|---------|
| 发生时机 | 由咒语/异能触发 | 战斗阶段 |
| 伤害来源 | 生物自身 | 攻击/阻挡生物 |
| 先攻/连击 | 不适用 | 适用 |
| 阻挡 | 无 | 需要宣告阻挡者 |
| 反击 | 不适用 | 阻挡生物可反击 |
| 战斗伤害步骤 | 跳过 | 需要 |

## 战略价值

### 1. 绿色去除
争斗是**绿色**最重要的去除手段之一。由于绿色通常缺乏直接消灭或放逐生物的效应，争斗提供了一种「以力量换力量」的去除方式。

### 2. 与死触的协同
如果你的生物具有死触（Deathtouch），则它只需在争斗中造成**1点伤害**即可消灭对方生物，无论对方力量多大。

### 3. 与系命的协同
若你的生物具有系命（Lifelink），争斗中造成的伤害也会为你恢复生命。

### 4. 与力量增幅的协同
在争斗前临时增幅自己生物的力量（如 +X/+X 的 trick），可以在争斗中战胜更强的对手。

## 单向伤害变体

部分咒语/异能让**一个生物对另一个生物造成伤害**，而非双向争斗：
- 例如 Rabid Bite：你的生物造成伤害，但对方生物不反击
- 这种单向变体更安全，常用于去除威胁
