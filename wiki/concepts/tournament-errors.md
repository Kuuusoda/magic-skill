# 比赛失误（Tournament Errors）

## 定义

比赛失误（Tournament Errors）是指违反《万智牌比赛规则》（MTR）的行为，与违反《完整规则》的「游戏行动失误」相对应。这是 IPG 中三大违规类别之一，涵盖了对比赛流程和比赛规则本身的违反（IPG 3.0）。

## 核心原则

### 1. 与游戏行动失误的区别
- **游戏行动失误（GPE）**：违反 CR（如施放非法咒语、遗漏触发）
- **比赛失误（TE）**：违反 MTR（如迟到、牌表错误、未充分洗牌、违反换备规则）

### 2. 升级路径更严格
- 比赛失误对比赛流程的破坏性通常大于游戏行动失误
- 因此**第二次**收到同类型比赛失误的警告时，处罚就会**升级为一盘负（Game Loss）**
- 后续同类型的比赛失误继续为一盘负（不会继续升级到取消资格）（IPG 3.0）
- 多日比赛的处罚计数在次日清零

### 3. 非所有 MTR 违反都算违规
- 只有「较为严重」的 MTR 违反才需要处罚
- 如果违规行为未对比赛整体流程造成负面影响，裁判只需教育牌手，无需处罚（IPG 3.0）
- 但持续或故意无视规则可能需要进一步调查

## 主要分类

IPG 将比赛失误细分为以下九类：

### 1. 迟到（Tardiness）
- 牌手未在比赛规定的开始时间到场
- 常见判罚：一盘负（Game Loss）或比赛负（Match Loss），视迟到时间而定（IPG 3.1）

### 2. 场外援助（Outside Assistance）
- 牌手在对局期间接受局外人员（非对手、非裁判）的建议或信息
- 包括让旁观者看自己的手牌、使用电子设备查询信息等
- 判罚：Game Loss（IPG 3.2）

### 3. 标记牌张/套牌（Marked Cards / Deck）
- 套牌中的某些牌因物理差异（弯曲、磨损、不同卡套）可被辨认
- 可能给予警告并要求更换，严重时为 Game Loss（IPG 3.3）

### 4. 套牌/牌表问题（Deck / Decklist Problem）
- 牌表与实际套牌不一致（数量错误、登记了非法牌、未登记的牌出现在套牌中）
- 常见判罚：Game Loss（IPG 3.5）

### 5. 套牌登记问题（Decklist Problem）
- 牌表上牌名写错、数量登记错误
- 裁判通常会修正牌表，但可能附带 Game Loss（IPG 3.5）

### 6. 限制赛程序错误（Limited Procedure Violation）
- 在限制赛中违反了特定程序（如轮抽时看了不该看的牌、现开时牌张交换不当）
- 判罚通常为 Warning 或 Game Loss（IPG 3.6）

### 7. 沟通错误（Communication Policy Violation）
- 违反了关于游戏信息沟通的规则（如故意提供错误信息、对牌的描述具有误导性）
- 判罚视严重程度而定（IPG 3.7）

### 8. 不当决定胜负（Improperly Determining a Winner）
- 使用掷骰子、猜拳等方式决定胜负，而非通过正常对局
- 严重违规，通常为 Game Loss 或 Disqualification（IPG 3.8）

### 9. 未充分洗牌（Insufficient Shuffling）
- 牌手未能在合理时间内使套牌充分随机化
- 常见判罚：Warning，要求重新洗牌（IPG 3.9）

## 常见示例

| 情形 | 所属分类 | 典型判罚 |
|------|---------|---------|
| 比赛开始后 5 分钟仍未到场 | 迟到 | Game Loss |
| 牌表写了 4 张闪电击，套牌只有 3 张 | 套牌/牌表问题 | Game Loss |
| 套牌中有一张闪卡明显弯曲，可被切牌时辨认 | 标记牌张 | Warning / Game Loss |
| 轮抽时偷看了旁边牌手选的牌 | 限制赛程序错误 | Game Loss |
| 朋友在旁边提示你该出哪张牌 | 场外援助 | Game Loss |
| 洗牌后对手切牌时发现牌序可预测 | 未充分洗牌 | Warning |

## 修正理念

比赛失误的修正通常不涉及「倒回游戏状态」，而是：
- 修正牌表或套牌的非法状态
- 要求牌手更换标记的牌张或卡套
- 在严重情况下，直接判负或取消资格

## 牌手建议

- **提前到场**：避免因迟到而直接被判 Game Loss
- **仔细检查牌表**：提交前核对数量、牌名和合法性
- **使用统一卡套**：避免闪卡弯曲或不同批次卡套造成标记
- **充分洗牌**：每次换备、再调度、搜寻牌库后都认真洗牌
- **不要在比赛中与他人讨论对局**：即使是休息时间也可能构成场外援助
