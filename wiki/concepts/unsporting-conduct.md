# 举止违背运动道德（Unsporting Conduct）

## 定义

举止违背运动道德（Unsporting Conduct）是指可能对比赛的安全、竞争性、乐趣或公平性造成严重负面影响的干扰性行为。这是 IPG 中三大违规类别之一，也是处罚最为严厉的一类（IPG 4.0）。

## 核心原则

### 1. 与「缺乏运动家精神」的区别
- **举止违背运动道德**：干扰性的、破坏性的行为
- **缺乏运动家精神**：不友好、冷淡、不握手等行为
- 后者不构成本类违规。牌手有权保持「竞赛面孔」，不需要对对手友善（IPG 4.0）

### 2. 主审是最终仲裁者
- 只有主审（Head Judge）有权最终判定某种行为是否属于举止违背运动道德
- 巡场裁判可以给出判罚，但牌手可上诉
- 涉及 Game Loss 或更严厉处罚时，必须获得主审同意；取消资格必须由主审亲自执行（IPG 4.0）

### 3. 先控制局面，后处理判罚
- 裁判的首要任务是防止事态升级
- 若牌手情绪激动，应先安抚，待场面可控后再进行违规判定和处罚（IPG 4.0）

## 四大分级

### 1. 轻微（Minor）
- **定义**：对比赛造成轻微干扰的行为，如不耐烦的言语、轻微的抱怨
- **典型判罚**：Warning（警告）
- **常见情形**：反复催促对手、对裁判判决小声抱怨、故意拖延但不构成慢打（IPG 4.1）

### 2. 中度（Major）
- **定义**：对比赛造成明显干扰的行为，如言语侮辱、威胁、故意破坏比赛物品
- **典型判罚**：Game Loss（一盘负）
- **常见情形**：辱骂对手或裁判、摔牌、将饮料洒在牌上、威胁性言语（IPG 4.2）

### 3. 严重（Serious）
- **定义**：对比赛安全或公平性造成严重威胁的行为
- **典型判罚**：Match Loss（一局负）或 Disqualification（取消资格）
- **常见情形**：身体攻击、盗窃、故意破坏他人财物、严重骚扰（IPG 4.3）

### 4. 作弊（Cheating）
- **定义**：故意违反规则以获取优势的行为，且牌手清楚自己违反了规则
- **典型判罚**：Disqualification（取消资格）
- **关键要素**：必须是**故意的**、**为了获取优势**、**牌手知道自己违反了规则**
- **常见情形**：偷看对手手牌、在套牌中藏额外的牌、贿赂对手、故意错误描述牌的效果（IPG 4.8）

## 常见示例

| 情形 | 分级 | 典型判罚 |
|------|------|---------|
| 对对手说"你打得真烂" | 轻微 | Warning |
| 辱骂对手或裁判，使用侮辱性语言 | 中度 | Game Loss |
| 故意摔牌、撕毁自己的套牌登记表 | 中度 | Game Loss |
| 威胁要殴打对手 | 严重 | Match Loss / Disqualification |
| 在比赛中偷看对手牌库顶的牌 | 作弊 | Disqualification |
| 贿赂对手让其故意输掉比赛 | 作弊 | Disqualification |
| 套牌中秘密多放了一张牌 | 作弊 | Disqualification |

## 作弊（Cheating）详解

作弊是举止违背运动道德中最严重的一种，有四个必须同时满足的条件：

1. **违反规则**：牌手做出了违反 CR 或 MTR 的行为
2. **故意为之**：该行为是有意识的，不是无意的失误
3. **意图获取优势**：牌手这么做的目的是为了在比赛中获得不公平的优势
4. **知道自己在违反规则**：牌手清楚自己的行为是违规的

如果以上四个条件**不能同时满足**，则不构成作弊，可能归入其他类别的违规。例如：
- 一位新手无意中记错了牌的效果 → 属于「违反游戏规则」（GPE），不是作弊
- 牌手故意利用了一个复杂的规则漏洞，但真心相信自己是对的 → 可能不是作弊，但需深入调查

## 牌手建议

- **保持冷静**：情绪失控是引发中度/严重违规的最常见原因
- **尊重裁判**：即使不同意判决，也应通过正当申诉渠道解决，而非当场争吵
- **不要触碰对手的牌或物品**：未经允许不要碰对手的东西
- **诚实为上**：如果不确定规则，呼叫裁判询问，远比事后被发现有欺骗行为要好
- **注意言辞**：避免使用可能被视为威胁或侮辱的语言，即使是在开玩笑
