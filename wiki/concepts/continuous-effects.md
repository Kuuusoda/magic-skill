# 持续性效应（Continuous Effects）

## 定义

持续性效应是会持续一段时间并改变游戏状态的效应。与一次性效应不同，持续性效应不会只发生一次，而是在满足条件期间内持续影响游戏（CR 611）。

## 持续性效应的类型

### 1. 改变叙述的效应（Text-Changing Effects）
直接改变牌的规则叙述文字（CR 612）。例如：「目标生物失去所有异能。」

### 2. 改变特征值的效应
改变物件的颜色、类别、力量/防御力、法术力费用等特征。这是最常见的持续性效应类型（CR 613）。

### 3. 改变规则的效应
添加、移除或改变游戏规则。例如：「你可以每回合额外使用一个地。」

---

## 层级系统（Layer System）

当多个持续性效应同时影响同一个物件时，万智牌使用**层级系统**来决定哪个效应优先生效（CR 613.1）。层级按以下顺序应用：

### 七大层级

| 层级 | 内容 | 子层级 |
|------|------|--------|
| **层 1** | 可复制特征和复制效应 | 无 |
| **层 2** | 改变控制权的效应 | 无 |
| **层 3** | 改变叙述的效应（非改变异能） | 无 |
| **层 4** | 改变类别的效应 | 无 |
| **层 5** | 改变颜色的效应 | 无 |
| **层 6** | 添加或移除异能的效应 | 无 |
| **层 7** | 改变力量/防御力的效应 | 7a-7e |

### 层 7 的五个子层级（P/T 层）

层 7 是最复杂的层级，专门处理力量/防御力的改变：

- **7a**：设定 P/T 为特定数值的效应（如「此生物基础力量与防御力为 4/4」）
- **7b**：设定 P/T 为某数值的替代性数值（如「此生物的力量等同于你坟墓场中的牌数」）
- **7c**：修改 P/T 但不设定的效应（如「+1/+1 指示物」）
- **7d**：以其他方式修改 P/T 的效应（如「所有你操控的生物获得 +2/+0」）
- **7e**：交换力量和防御力的效应（如「交换此生物的力量和防御力」）

### 时间印记（Timestamp）

在同一层级内，若多个效应发生冲突，通常以**时间印记**决定顺序：
- 先进入战场的效应或先产生的效应先生效
- 后生效的效应覆盖先生效的效应

**例外**：在层 7 中，若一个效应设定了基础 P/T，而另一个效应只是修改 P/T，则设定效应始终先应用，修改效应后应用。

## "不能"优先于"可以"

当一个规则或效应允许某事发生，而另一个持续性效应说某事不能发生时，**"不能"的效应优先**（CR 101.2）。

例如：
- 效应 A：「你本回合可以额外使用一个地」
- 效应 B：「你本回合不能使用地」
- **结果**：你不能使用地

---

## 依赖关系（Dependencies）

在某些情况下，一个持续性效应的存在会影响另一个效应是否应该生效。这种情况下，被依赖的效应先应用（CR 613.7）。

例如：
- 效应 A：「所有树林都是 1/1 绿色生物」
- 效应 B：「所有你操控的生物是 2/2」
- 分析：效应 B 依赖于效应 A（因为 B 只对生物生效），所以 A 先应用，然后 B 应用，树林生物最终是 2/2。

---

## 常见误区

### 一次性效应 vs 持续性效应
- **一次性**：「对目标生物造成 3 点伤害」（伤害发生后即结束）
- **持续性**：「目标生物获得 -2/-2 直到回合结束」（在持续期间内一直有效）

### "直到回合结束"的结束时机
持续到"直到回合结束"的效应在**清除步骤**中才结束（CR 514.2），而不是在结束步骤或战斗后行动阶段结束时。
