# 搭载（Crew）

## 定义

搭载（Crew）是载具（Vehicle）这一神器副类别专属的关键字动作。它允许牌手横置任意数量自己操控、且总力量大于或等于搭载数值的生物，使该载具在本回合结束前变成神器生物（CR 301，CR 702.122）。

## 核心规则

### 标准格式
```
搭载 N（横置任意数量由你操控的生物：此载具成为神器生物直到回合结束，其力量与防御力分别为载具上标示的数值。横置的生物之总力量须等于或大于 N 才行。）
```

### 使用限制
- 只能横置**由你操控的生物**
- 横置的生物**总力量**必须**大于或等于**搭载数值
- 搭载可以在**任何拥有优先权的时机**执行（特殊动作，不使用堆叠）
- 刚进入战场、具有召唤失调的生物**可以**被横置来搭载（不同于攻击或起动 {T} 异能）

### 变成生物
- 搭载后，载具成为**神器生物**直到回合结束
- 它获得其牌面右下角标示的**力量/防御力**
- 它保留其原有异能（如飞行、先攻等）
- 回合结束时，它变回非生物神器（不再具有力量/防御力）

### 与召唤失调
- 载具本身不受召唤失调限制（因为它不是生物）
- 刚打出载具的当回合就可以搭载它
- 这是载具相比普通生物的重大优势

## 战略价值

### 1. 躲避去除
载具在非搭载状态下**不是生物**，因此不受只对生物生效的去除影响（如 Doom Blade、Fatal Push）。这让它在对手回合中相对安全。

### 2. 回合外搭载
由于搭载是特殊动作，可以在对手回合中执行（只要你拥有优先权）。这让载具在对手的进攻阶段也能作为阻挡者出现。

### 3. 与 Token 套牌协同
Token 套牌通常有大量廉价小生物，是理想的搭载「燃料」：
- 1/1 士兵可以搭载 Smuggler's Copter（搭载 1）
- 多个小生物可以合力搭载大型载具

### 4. 载具套牌
纯载具套牌（Vehicle Tribal）专注于快速打出廉价载具，然后用大量生物持续搭载，形成连续进攻压力。

## 与武具的区别

| 特性 | 载具（Vehicle） | 武具（Equipment） |
|------|----------------|------------------|
| 类型 | 神器（可变生物） | 神器 |
| 搭载方式 | 横置生物 | 支付费用 |
| 附着关系 | 不需要附着于生物 | 必须佩带在生物上 |
| 回合结束 | 变回非生物神器 | 保持佩带状态 |
| 被去除 | 作为神器被去除 | 作为神器被去除，生物保留 |

## 历史

- 搭载首次出现于 **Kaladesh（卡拉德许，2016）**
- 作为印度蒸汽朋克主题的标志性机制
- Smuggler's Copter 因过于强势在标准赛中被禁
- Heart of Kiran 在多个标准环境中作为顶级曲线
- 后来在 **Aether Revolt**、**Neon Dynasty** 和 **The Brothers' War** 中回归
