# EDH 社交契约（Social Contract）

## 定义

社交契约（Social Contract）是指挥官（EDH）赛制中一种非正式的、基于玩家共识的「游戏规则」。它规定了牌手之间期望的游戏体验强度、互动水平和行为准则。与官方规则（CR/MTR）不同，社交契约没有书面条文，而是通过玩家之间的沟通和默契来执行。

社交契约是指挥官赛制区别于其他万智牌赛制的核心特征之一——它使指挥官既可以是最轻松的休闲游戏，也可以是最激烈的竞技对抗。

## 核心原则

### 1. 乐趣优先

指挥官赛制的首要目标是让所有参与者享受游戏：
- 不是每个人都想玩 cEDH 级别的组合技套牌
- 也不是每个人都想花 3 小时打一盘游戏
- 目标是找到**所有人都满意的强度水平**

### 2. 预先沟通

在开始游戏前，牌手应该沟通以下问题：

| 问题 | 说明 |
|------|------|
| **套牌强度（Power Level）** | 你的套牌是 1-10 中的几级？ |
| **是否有无限组合技？** | 是否包含可立即获胜的无限组合？ |
| **Mass Land Destruction？** | 是否包含大规模破坏地的牌（如 Armageddon）？ |
| **Stax / Lock？** | 是否包含大量封锁对手行动的牌？ |
| **Tutors 密度** | 套牌中有多少张搜索牌库的牌？ |
| **预算限制** | 是否有预算上限？ |
| **主题偏好** | 是否要求套牌有特定主题？ |

### 3. 尊重对手

- 不隐瞒套牌中的无限组合技
- 不在对手明确表示休闲时拿出 cEDH 套牌
- 允许对手「回退」明显的操作失误（尤其在休闲级别）
- 不对新手使用过于复杂的规则陷阱

## 强度分级（Power Level）

指挥官社区通常使用 1-10 的强度分级系统：

| 等级 | 名称 | 特征 | 典型回合 |
|------|------|------|---------|
| **1-3** | 预组/新手 | 使用预组套牌或自行组装的主题套牌，无 tutors，无组合技 | 15+ |
| **4-5** | 休闲优化 | 有明确的主题，少量优化，可能有慢速组合技 | 10-15 |
| **6-7** | 中强度 | 有 tutors 和去除，有组合技但不是主策略 | 7-10 |
| **8-9** | 高强度 | 组合技为主，大量 tutors，高互动密度 | 5-7 |
| **10** | cEDH | 最大化获胜概率，最快组合技，最高互动 | 1-4 |

**注意**：不同群体对「强度等级」的定义可能不同。最可靠的方式是具体描述你的套牌特征，而非只说一个数字。

## 常见争议话题

### 1. 无限组合技（Infinite Combos）

| 观点 | 支持者 |
|------|--------|
| 「无限组合技破坏了休闲游戏的乐趣」 | 休闲玩家 |
| 「无限组合技是游戏的一部分，可以用互动牌应对」 | 竞技倾向玩家 |
| 「可以玩无限组合技，但需要给对手反应时间」 | 折中派 |

**建议做法**：
- 在明确标为「cEDH」的对局中，无限组合技是常态
- 在休闲对局中，应事先声明套牌中包含无限组合技
- 部分桌游店设置「无无限组合技」桌

### 2. Mass Land Destruction（MLD）

大规模破坏地牌的效应（如 Armageddon、Ravages of War）：

| 观点 | 说明 |
|------|------|
| 「MLD 让游戏变得无聊」 | 破坏后所有人都无法行动 |
| 「MLD 是合法策略」 | 在构筑赛中完全合法 |
| 「只有在能立即获胜时使用 MLD 才可接受」 | 折中观点 |

**社区共识**：在大多数休闲桌，MLD 被视为「不友好」的行为，除非事先约定允许。

### 3. Stax / Lock 套牌

Stax（源自 Smokestack）是指使用规则限制牌封锁对手行动的套牌：

| 牌名 | 效应 |
|------|------|
| Rule of Law | 每位牌手每回合只能施放一个咒语 |
| Stony Silence | 神器失去所有异能 |
| Blood Moon | 所有非基本地变为山脉 |
| Rest in Peace | 坟场中的牌改为放逐 |

**争议点**：Stax 使对手几乎无法玩游戏，但在 cEDH 中是完全合法的策略。

### 4. 快速获胜（Fast Combo）

在第一回合或前几回合就达成获胜条件的组合技：

| 回合 | 示例 | 争议度 |
|------|------|--------|
| 回合 1 | Flash + Protean Hulk | 极高 |
| 回合 2 | Mana Crypt + Sol Ring → 指挥官 → 组合技 | 高 |
| 回合 3-4 | 典型 cEDH 速度 | 中（在 cEDH 桌正常） |

## 社交契约的边界

### 什么是可以协商的

- 套牌强度匹配
- 是否允许无限组合技
- 是否允许 MLD
- 对局时长预期
- 是否允许「回退」操作失误

### 什么是不可以协商的

- 官方规则（CR）必须遵守
- 禁牌表必须遵守
- 作弊绝不可接受
- 尊重其他玩家的人身和财产

## cEDH 中的社交契约

在 cEDH 环境中：
- 社交契约几乎不存在——所有策略都是合法的
- 但仍有基本礼仪：
  - 不故意拖延时间
  - 清晰宣布自己的行动
  - 接受对手的获胜（不因为「太快」而抱怨）

## 如何建立良好的社交契约

### 作为主持人

1. **开始前询问**：「大家的套牌大概在什么强度？」
2. **推荐匹配**：将相似强度的玩家分在一起
3. **设置预期**：「这一桌允许组合技，但请在获胜前给对手展示组合链」
4. **准备备用套牌**：如果强度不匹配，可以提供低强度备用套牌

### 作为参与者

1. **诚实描述**：不要故意低估套牌强度
2. **准备多副套牌**：不同强度的套牌应对不同场合
3. **灵活调整**：如果发现强度不匹配，主动降低强度或更换套牌
4. **接受多样性**：不是每局游戏都需要获胜，有时体验主题套牌也是一种乐趣
