# 统帅区（Command Zone）

## 定义

统帅区（Command Zone）是万智牌中的一个特殊游戏区域，专属于指挥官（Commander/EDH）赛制。它是指挥官的起始位置，也是指挥官在整场游戏中可以反复回归的「大本营」（CR 903.6）。

在标准万智牌规则中，统帅区也用于放置徽记（Emblem）和景点牌（Attraction Cards），但在指挥官赛制中，它的核心功能是容纳指挥官。

## 核心规则

### 起始位置

- 游戏开始时，每位牌手的指挥官面朝上放置于其统帅区（CR 903.6）
- 指挥官**不在套牌中**，因此不受抽牌、洗牌、牌库搜索等效应的影响
- 统帅区中的牌对所有牌手可见

### 从统帅区施放指挥官

- 牌手可以在其拥有优先权时从统帅区施放其指挥官（CR 903.7）
- 施放指挥官遵循正常的咒语施放规则（选择模式、目标、支付费用等）
- 指挥官从统帅区施放时，其法术力费用正常计算

### 指挥官的替代性移动

这是指挥官赛制最具特色的规则之一（CR 903.9）：

> 若一个指挥官将从战场进入坟墓场或放逐区，其拥有者可以**选择**将其放入统帅区，而非进入该目标区域。

**关键特性**：
- 这是**替代性效应**，不使用堆叠，对手无法响应
- 由指挥官的**拥有者**（而非操控者）决定是否移回统帅区
- 若指挥官将被洗入牌库，不能选择移回统帅区（只能进入牌库）
- 若指挥官将从战场返回手牌，不能选择移回统帅区

**战略意义**：
- 指挥官几乎不可能被彻底去除（除非被放逐并封锁统帅区回归，或洗入牌库）
- 这使得指挥官可以反复被施放，成为持续的资源来源
- 也是「统帅税」存在的原因——防止指挥官被无限次免费召回

### 指挥官进入统帅区的其他方式

除替代性移动外，指挥官还可以通过以下方式进入统帅区：
- 被特定异能直接放入统帅区（如 Command Beacon）
- 某些效应允许将牌从其他区域移入统帅区

## 统帅区与指挥官税

每次指挥官从统帅区被施放后，若该指挥官此前已从统帅区进入过其他区域，则下一次从统帅区施放需要额外支付 {2}。这一额外费用称为**统帅税**（Commander Tax），在统帅区中累积（CR 903.8）。

详见 [[commander-tax|指挥官税]] 页面。

## 统帅区与其他区域的区别

| 特性 | 统帅区 | 手牌 | 战场 | 坟墓场 | 牌库 | 放逐区 |
|------|--------|------|------|--------|------|--------|
| 公开性 | 公开 | 私密 | 公开 | 公开（通常） | 私密 | 公开（通常） |
| 牌手可见 | 全部 | 仅拥有者 | 全部 | 全部 | 仅拥有者 | 全部 |
| 可被搜索 | 否 | 否 | 否 | 否 | 是 | 否 |
| 可被抽牌 | 否 | 否 | 否 | 否 | 是 | 否 |
| 可被互动 | 极少 | 是 | 是 | 是 | 极少 | 是 |

## 统帅区的战略价值

### 1. 始终可及的资源

指挥官位于统帅区意味着：
- 你**始终可以施放**你的指挥官（只要支付费用）
- 不受手牌随机性的影响
- 不受对手弃牌、去除等手牌破坏手段的影响

### 2. 反复利用

通过替代性移动规则，指挥官可以：
- 被施放 → 进入战场 → 被去除 → 回到统帅区 → 再次施放
- 每次施放都可以触发 ETB（进场）异能
- 配合 blink/flicker 效应可以额外触发

### 3. 社会契约考量

在休闲 EDH 环境中，反复施放指挥官（尤其是高费指挥官）可能被视为「拖慢游戏节奏」。cEDH 中则充分利用这一机制。

## 统帅区在多人游戏中的特殊性

在指挥官赛制的多人游戏中：
- 每位牌手都有自己的统帅区
- 每个统帅区相互独立
- 牌手只能看到自己的指挥官，不能看到其他牌手的统帅区内容（虽然通常也可见）
- 某些效应可以影响所有统帅区中的牌（如总罕言）
