# 指示物（Counters）

## 定义

指示物是放在永久物上用于记录数量或状态的小标记。它们是游戏状态的一部分，可以影响永久物的特征、异能或游戏规则（CR 122）。

## 最常见的指示物类型

### +1/+1 指示物
- **效果**：每个 +1/+1 指示物使生物的力量和防御力各 +1
- **相互作用**：+1/+1 指示物和 -1/-1 指示物在同一永久物上会成对抵消（CR 122.3）
- **策略价值**：绿色和白色的核心机制之一，常用于成长型生物和 token 套牌

### -1/-1 指示物
- **效果**：每个 -1/-1 指示物使生物的力量和防御力各 -1
- **特殊规则**：如果一个生物的防御力降到 0 或更小（包括因 -1/-1 指示物），它会在状态动作检查时被消灭
- **与 +1/+1 抵消**：当同一永久物上同时存在两种指示物时，成对移除直到只剩一种

### 忠诚指示物（Loyalty Counters）
- **放置对象**：鹏洛客
- **效果**：表示鹏洛客的忠诚度数值
- **规则**：鹏洛客的忠诚异能在起动时会增加或减少忠诚指示物
- **死亡条件**：当鹏洛客上的忠诚指示物为 0 时，它被置入坟墓场（CR 704.5i）

### 其他常见指示物
- **中毒指示物（Poison Counters）**：在指挥官等赛制中使用，累积到一定数量会导致输牌
- **能量指示物（Energy Counters）**：卡拉德许机制，用于支付特定费用
- **经验指示物（Experience Counters）**：指挥官机制，累积后增强某些牌的效果
- **贮藏指示物（Storage Counters）**：用于记录累积资源的数量
- **时间指示物（Time Counters）**：用于延迟触发或倒数机制（如 Suspend）

## 指示物的规则要点

### 指示物不是物件
指示物本身不是游戏物件，不能被选择为目标，也不会进入堆叠。放置或移除指示物是一次性效应，不使用堆叠。

### 指示物与特征改变
指示物会改变永久物的特征值。例如：
- 一个 2/2 生物上有两个 +1/+1 指示物，它实际上是一个 4/4 生物
- 这在计算伤害分配、目标合法性、触发条件时都非常重要

### 指示物的移除
当某个效应要求移除指示物时：
- 如果没有指定类型，通常从该永久物上移除任意类型的指示物
- 某些效应只移除特定类型的指示物（如"移去所有 -1/-1 指示物"）

### 衍生物上的指示物
衍生物和永久物一样可以接受指示物。当衍生物离开战场时，它消失，其上的所有指示物也随之消失。

## 放置指示物 vs 获得指示物

- **放置（Put）**：将指示物物理放在永久物上
- **获得（Get/Have）**：永久物因指示物而获得对应的数值修正

在某些规则文本中，这两个词可以互换使用，但"放置"更常用于描述动作，"获得"更常用于描述结果。

## 常见误区

### "移去指示物"与"消灭"
移去指示物不是消灭生物。即使一个生物失去了所有 +1/+1 指示物，只要其基础防御力大于 0 且未受到致命伤害，它仍然存活。

### 指示物与触发式异能
"当此生物上放置一个 +1/+1 指示物时"是触发式异能，会在指示物放置后触发。
