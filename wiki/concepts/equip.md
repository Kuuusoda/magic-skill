# 佩带（Equip）

## 定义

佩带（Equip）是武具（Equipment）这一神器副类别专属的起动式异能。它允许武具的操控者支付费用，将该武具移动到目标生物上，使该生物获得武具提供的加成或异能（CR 301，CR 702.6）。

## 核心规则

### 标准格式
```
佩带 {N}（{N}：将此武具佩带在目标由你操控的生物上。只能于法术力时机起动。）
```

### 使用限制
- **法术力时机**：佩带异能只能在拥有优先权且堆叠为空时起动（即通常只能在行动阶段起动）（CR 702.6）
- **目标限制**：目标必须是**由你操控的生物**（除非某张牌的异能明确允许其他情况，如 `{N}：将此武具佩带在目标生物上。`）
- **无召唤失调**：武具神器本身不受召唤失调限制，但起动佩带异能需要拥有优先权
- **装备中的武具**：如果武具已佩带在某生物上，再次起动佩带异能会将其从原生物上移走，贴附到新目标上

### 与灵气（Aura）的区别

| 特性 | 武具（Equipment） | 灵气（Aura） |
|------|------------------|-------------|
| 类型 | 神器 | 结界 |
| 移动性 | 可反复佩带/卸下 | 结附后固定，除非被去除 |
| 目标条件 | 佩带异能指定生物 | 施放时选择结附目标 |
| 离开战场 | 留在战场（变回未佩带状态） | 进入坟墓场 |
| 被消灭 | 作为独立永久物留在战场 | 进入坟墓场 |

## 战略价值

### 1. 灵活性
武具的最大优势在于 reusable——一个武具可以在多个生物之间转移，即使当前的「载体」被去除，武具本身仍然留在战场上。

### 2. 组合技潜力
某些武具具有极强的组合技价值：
- **Skullclamp**：在牺牲套牌中作为抽牌引擎
- **Colossus Hammer**：配合 Sigarda's Aid 或 Puresteel Paladin 免费佩带
- **Lightning Greaves**：保护关键生物，在 commander 中广泛使用

### 3. 与「交给你操控」的协同
当生物的操控权改变时，贴附在其上的武具并不会自动移走（除非异能另有说明）。这让武具在 theft 效应中也能发挥作用。
