# 集军（Amass）

## 定义

集军（Amass）是万智牌中的关键字动作，创造或增强一个名为**军队（Army）**的衍生生物。若你尚未操控军队衍生物，集军会创造一个 0/0 的 Zombie Army（灵俑军队）衍生生物并在其上放置指定数量的 +1/+1 指示物；若你已操控军队，则直接在现有军队上放置 +1/+1 指示物（CR 701.43）。

## 核心规则

### 标准叙述
```
集军 N。（若你未操控军队，创造一个 0/0 黑色灵俑军队衍生生物生物。在其上放置 N 个 +1/+1 指示物。若你操控军队，改为在其上放置 N 个 +1/+1 指示物。）
```

### 关键特性
- **唯一军队**：你同时只能操控一个 Army 衍生物。若某效应要创造第二个 Army，改为在现有 Army 上放置指示物
- **+1/+1 指示物增长**：集军的核心是不断累积 +1/+1 指示物，让军队越来越大
- **黑色灵俑**：军队衍生物是黑色、灵俑（Zombie）、军队（Army）生物
- **可被去除**：虽然军队可以不断变大，但它仍然是一个单一永久物，消灭或放逐效应可以一次性清除所有累积的投入

### 创造军队
若你未操控 Army，第一次集军时：
1. 创造一个 0/0 的黑色 Zombie Army 衍生生物
2. 在其上放置 N 个 +1/+1 指示物（使其成为 N/N 生物）

### 增强军队
若你已操控 Army，后续集军时：
1. 在现有 Army 上放置 N 个 +1/+1 指示物
2. 军队的力量和防御力各增加 N

## 战略价值

### 1. 渐进式威胁
集军提供了一种「投资型」威胁：每次集军都让军队变得更大，对手若不及时去除，最终将面对一个无法阻挡的巨型生物。

### 2. 与 +1/+1 指示物协同
集军与所有 +1/+1 指示物机制完美配合：
- **Hardened Scales**：集军时额外放置指示物
- **Corpsejack Menace**：翻倍放置的指示物数量
- **Inspiring Call**：保护所有带指示物的生物

### 3. 牺牲再利用
军队是单一大型生物，可以被牺牲来触发各种效应（如 Eldritch Evolution、Fling），将累积的力量转化为其他价值。

### 4. 与 Army tribal 配合
某些牌专门与 Army 互动：
- Dreadhorde Twins：军队攻击时创造衍生生物
- Gleaming Overseer：军队获得辟邪和威胁

## 历史

- 集军首次出现于 **War of the Spark（火花之战，2019）**
- 作为 Nicol Bolas 入侵拉尼卡的故事背景机制，体现「召集军队」的主题
- 设计目的是提供一个可以跨颜色使用（主要在蓝黑红中）的衍生物机制
- 在 **Commander Legends** 和后续系列中少量回归
- 集军是万智牌中少数将「衍生物类别（Army）」作为核心机制的设计
