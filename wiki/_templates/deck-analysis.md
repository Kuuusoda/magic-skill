# {{套牌中文名}}（{{Archetype}}）套牌分析

> **使用指南**：本模板用于摩登 / 先驱 / 现代 / 永恒 等构筑赛制的完整套牌分析。
> 每节标记 `[必填]` 的禁止省略；`[可选]` 视套牌特点取舍。
> 完成后必须通过文末"质量检查清单"逐条核对，任一未达标禁止输出。

## 元数据 [必填]

- **分析日期**：YYYY-MM-DD
- **数据样本量**：N 份真实牌表（来源：MTGTop8 / mtgdecks.net / MTGGoldfish）
- **数据时间范围**：YYYY-MM-DD 至 YYYY-MM-DD
- **当前 Meta 占比**：X.X%（来源：YYYY-MM-DD 摩登快照）
- **Tier 分级**：Tier 1 / Tier 2 / Tier 3 / 角落选择
- **变体分布**：变体 A — N 份；变体 B — N 份；本页主要分析的变体

> 若多份变体差异显著（如 4+ 张主牌不同），需要在套牌定位中说明并选择其一为主分析对象。

## 一、套牌定位（Deck Identity）[必填]

- **原型分类**：[Aggro / Midrange / Control / Combo / Tempo / Prison / Ramp]
- **核心赢牌路径**：一句话描述如何赢（含具体单卡 + 关键回合）
- **关键回合（Goldfish Turn）**：Tn — 在无干扰情况下最快几回合 kill
- **操作难度**：低 / 中 / 高（说明难点：调度 / 弹性 / 时序判断）
- **Meta 适配性**：在当前环境中的总体定位（克制了什么、被什么克制）
- **优势对局速览**：列出 2-3 个明显优势对手 + 一句原因
- **劣势对局速览**：列出 2-3 个明显劣势对手 + 一句原因
